1. Colab이란?

Colab은 웹 브라우저에서 Python 코드를 실행할 수 있는 실습 환경입니다.

별도의 Python 설치나 개발환경 설정 없이 사용할 수 있기 때문에, 이번 수업에서는 Python 문법 실습 환경으로 사용합니다.

Python 설치 필요 없음
별도 개발환경 설정 필요 없음

Google 계정 + 웹 브라우저
        ↓
      Colab
        ↓
   Python 바로 실행

2. Colab의 특징

  • 브라우저에서 바로 Python 코드를 실행할 수 있습니다.
  • 코드와 설명을 하나의 노트북 파일에 함께 저장할 수 있습니다.
  • 표, 그래프, 이미지 같은 실행 결과를 바로 확인할 수 있습니다.
  • GPU가 필요한 실험도 비교적 쉽게 시작할 수 있습니다.
  • 최근에는 Gemini, Learn Mode, MCP, CLI 같은 AI 관련 기능도 함께 확장되고 있습니다.

💡 참고: MCP(Model Context Protocol)는 AI가 외부 도구나 데이터를 연결해서 사용할 수 있도록 돕는 표준 방식입니다.

4. 연습문제

1부터 100까지 자연수 중 짝수의 합을 구하시오.

5. 방법 1: 기본 코드 실행하기

total = 0

for i in range(1, 101):
    if i % 2 == 0:
        total += i

print(total)

6. 방법 2: 코드를 간결하게 쓰고 표로 보기

sum(range(2, 101, 2))
evens = [n for n in range(1, 101) if n % 2 == 0]

print(evens)
print(sum(evens))

GPU 세팅과 확인

  2. 런타임 유형 변경을 선택합니다.
  3. 하드웨어 가속기를 GPU로 선택합니다.
  4. 아래 코드를 실행해서 GPU가 연결되었는지 확인합니다.

if torch.cuda.is_available():
    print("GPU 사용 가능")
    print(torch.cuda.get_device_name(0))
else:
    print("GPU를 사용할 수 없습니다.")

⚠️ 주의: GPU가 연결되지 않았다면 런타임 유형을 다시 확인합니다.
