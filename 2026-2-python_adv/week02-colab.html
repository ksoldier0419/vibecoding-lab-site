# Google Colab 시작하기

이미지 설명
Colab 바로가기

1. Colab이란?

Colab은 웹 브라우저에서 Python 코드를 실행할 수 있는 실습 환경입니다.

별도의 Python 설치나 개발환경 설정 없이 사용할 수 있기 때문에, 이번 수업에서는 Python 문법 실습 환경으로 사용합니다.

Python 설치 필요 없음
별도 개발환경 설정 필요 없음

Google 계정 + 웹 브라우저
        ↓
      Colab
        ↓
   Python 바로 실행

2. Colab의 특징

  • 브라우저에서 바로 Python 코드를 실행할 수 있습니다.
  • 코드와 설명을 하나의 노트북 파일(.ipynb)에 함께 저장할 수 있습니다.
  • 표, 그래프, 이미지 같은 실행 결과를 바로 확인할 수 있습니다.
  • GPU가 필요한 실험도 비교적 쉽게 시작할 수 있습니다.
  • 최근에는 Gemini, Learn Mode, MCP, CLI 같은 AI 관련 기능도 함께 확장되고 있습니다.

💡 참고: MCP(Model Context Protocol)는 AI가 외부 도구나 데이터를 연결해서 사용할 수 있도록 돕는 표준 방식입니다.

3. 예전 Colab과 지금 Colab

3.1 예전

  • 브라우저에서 Python 실행
  • GPU가 필요하면 Colab 사용
  • .ipynb 파일로 저장
  • VS Code에서 만든 코드를 Colab에 복사해서 실행

3.2 현재

최근 Colab은 단순한 클라우드 Jupyter Notebook에서, AI가 코드 작성과 실행 과정을 더 많이 도와주는 환경으로 확장되고 있습니다.

예를 들어 Gemini에게 목표를 설명하면, 코드 작성, 실행, 오류 수정, 결과 분석까지 이어서 도와줄 수 있습니다.

colab --gpu A100
colab exec -f train.py
colab download result.txt

- 반복문을 사용한다.
- if문을 사용한다.

6. 방법 2: 코드를 간결하게 쓰고 표로 보기

6.1 Pythonic 기법 사용하기

Python에는 반복문을 더 짧게 표현하는 방법도 있습니다.

6.2 내장 함수 결합

sum(range(2, 101, 2))

6.3 List Comprehension

evens = [n for n in range(1, 101) if n % 2 == 0]

print(evens)
print(sum(evens))

💡 참고: List Comprehension은 리스트를 만드는 짧은 문법입니다. 처음에는 어려울 수 있으므로, 기본 for문을 이해한 뒤 비교해보면 좋습니다.

✅ AI를 사용할 때 확인할 점

  • AI가 만든 코드가 문제 조건과 맞는지 확인합니다.
  • 실행 결과가 예상과 같은지 확인합니다.
  • 모르는 문법이 나오면 바로 복사하지 말고 의미를 먼저 물어봅니다.

8.2 GPU 세팅과 확인

GPU가 필요한 실습을 할 때는 Colab 상단 메뉴에서 runtime 유형을 GPU로 바꿉니다.

일반적인 흐름은 다음과 같습니다.

  1. 상단 메뉴에서 런타임을 선택합니다.
  2. 런타임 유형 변경을 선택합니다.
  3. 하드웨어 가속기를 GPU로 선택합니다.
  4. 아래 코드를 실행해서 GPU가 연결되었는지 확인합니다.
이미지 설명
GPU runtime 설정 화면 
import torch

if torch.cuda.is_available():
    print("GPU 사용 가능")
    print(torch.cuda.get_device_name(0))
else:
    print("GPU를 사용할 수 없습니다.")

실행 결과에 GPU 사용 가능과 GPU 이름이 나오면 GPU를 사용할 수 있는 상태입니다.

⚠️ 주의: GPU가 연결되지 않았다면 런타임 유형을 다시 확인합니다.
