파이썬에서 문자열과 관련된 함수들은 다양한 문자열 조작 및 처리를 쉽게 할 수 있도록 도와줍니다. 아래는 파이썬 문자열 함수들을 정리한 표입니다.

1. 문자열 함수

함수/메서드설명예시
str.replace(old, new)지정한 문자열을 다른 문자열로 대체합니다.'hello'.replace('l', 'y') -> 'heyyo'
str.strip()문자열 양쪽 끝의 공백을 제거합니다.' hello '.strip() -> 'hello'
str.lstrip()문자열 왼쪽의 공백을 제거합니다.' hello'.lstrip() -> 'hello'
str.rstrip()문자열 오른쪽의 공백을 제거합니다.'hello '.rstrip() -> 'hello'
str.split(sep)문자열을 특정 구분자로 나누어 리스트로 반환합니다.'a,b,c'.split(',') -> ['a', 'b', 'c']
str.join(iterable)리스트, 튜플 등의 요소들을 문자열로 연결합니다.','.join(['a', 'b', 'c']) -> 'a,b,c'
str.find(sub)부분 문자열의 첫 번째 시작 인덱스를 반환합니다. 없으면 -1을 반환합니다.'hello'.find('l') -> 2
str.index(sub)부분 문자열의 첫 번째 시작 인덱스를 반환합니다. 없으면 오류가 발생합니다.'hello'.index('l') -> 2
str.count(sub)부분 문자열이 등장한 횟수를 반환합니다.'hello'.count('l') -> 2

str1 = "aa bb -aa ccaa"
str1.count("aa") # 3
str1.count("a") # 6
str.zfill(width)문자열의 길이를 지정하고, 부족한 부분을 0으로 채웁니다.'42'.zfill(5) -> '00042'
str.ljust(width)문자열을 주어진 너비에서 왼쪽 정렬하고 오른쪽에 공백을 추가합니다.'hello'.ljust(10) -> 'hello '
str.rjust(width)문자열을 주어진 너비에서 오른쪽 정렬하고 왼쪽에 공백을 추가합니다.'hello'.rjust(10) -> ' hello'
str.center(width)문자열을 주어진 너비에서 가운데 정렬하고 양쪽에 공백을 추가합니다.'hello'.center(10) -> ' hello '
str.capitalize()문자열의 첫 글자만 대문자로 변환합니다.'hello'.capitalize() -> 'Hello'
str.upper()문자열을 모두 대문자로 변환합니다.'hello'.upper() -> 'HELLO'
str.lower()문자열을 모두 소문자로 변환합니다.'HELLO'.lower() -> 'hello'
str.title()각 단어의 첫 글자를 대문자로 변환합니다.'hello world'.title() -> 'Hello World'
str.swapcase()대문자는 소문자로, 소문자는 대문자로 변환합니다.'Hello'.swapcase() -> 'hELLO'
str.startswith(prefix)문자열이 지정된 접두사로 시작하는지 확인합니다.'hello'.startswith('he') -> True
str.endswith(suffix)문자열이 지정된 접미사로 끝나는지 확인합니다.'hello'.endswith('lo') -> True
str.isalpha()문자열이 모두 알파벳 문자로 이루어졌는지 확인합니다.'hello'.isalpha() -> True
str.isdigit()문자열이 모두 숫자로 이루어졌는지 확인합니다.'123'.isdigit() -> True
str.isalnum()문자열이 모두 알파벳 문자 또는 숫자로 이루어졌는지 확인합니다.'hello123'.isalnum() -> True
str.isspace()문자열이 모두 공백 문자로 이루어졌는지 확인합니다.' '.isspace() -> True
str.islower()문자열의 알파벳이 모두 소문자인지 확인합니다.'hello'.islower() -> True
str.isupper()문자열의 알파벳이 모두 대문자인지 확인합니다.'HELLO'.isupper() -> True
str.partition(sep)문자열을 첫 번째 구분자를 기준으로 세 부분으로 나눕니다.'hello world'.partition(' ') -> ('hello', ' ', 'world')
str.rpartition(sep)문자열을 마지막 구분자를 기준으로 세 부분으로 나눕니다.'hello world'.rpartition(' ') -> ('hello', ' ', 'world')
str.format()문자열 안에 값을 넣거나 서식을 지정할 때 사용합니다.'{name} is {age}'.format(name='Alice', age=30) -> 'Alice is 30'

1.1 보충 설명

  • split(): 문자열을 특정 구분자를 기준으로 나누어 리스트로 반환합니다. 기본값은 공백입니다.
  • join(): 이터러블 객체의 각 요소를 연결해 하나의 문자열로 반환합니다.
  • replace(): 문자열의 특정 부분을 다른 문자열로 변경할 때 사용합니다.
  • find()와 index(): 문자열에서 특정 부분 문자열을 찾는 기능을 제공합니다. find()는 찾지 못하면 -1을 반환하고, index()는 오류를 발생시킵니다.

이 함수들을 사용하면 문자열의 처리와 변형을 매우 쉽게 할 수 있습니다.

2. 문자열 조작 예

import string

# 소문자 알파벳 생성
lowercase_alphabet = string.ascii_lowercase
print(lowercase_alphabet)

# 대문자 알파벳 생성
uppercase_alphabet = string.ascii_uppercase
print(uppercase_alphabet)

# 모든 알파벳 생성
all_alphabet = string.ascii_letters
print(all_alphabet)
실행 결과설명
abcdefghijklmnopqrstuvwxyz
ABCDEFGHIJKLMNOPQRSTUVWXYZ
abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ

[확인 항목]

string.ascii_lowercase, string.ascii_uppercase, string.ascii_letters가 어떤 문자열을 반환하는지 확인합니다.

정상 출력에서는 소문자 전체, 대문자 전체, 소문자와 대문자가 이어진 전체 알파벳 문자열이 순서대로 출력됩니다.
