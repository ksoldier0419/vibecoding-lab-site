전체 학생 관리 · 내 계정

과목별 명단을 먼저 등록하면 학생의 학번·이름을 대조하여 가입을 승인합니다.

교수 권한을 확인하고 있습니다.

과목 관리

과목코드는 등록 후 유지하고 과목명만 수정합니다. 이름을 변경해도 기존 수강 명단과 CSV의 과목코드는 그대로 사용할 수 있습니다. 수강생이 없는 과목만 삭제할 수 있습니다.

새 과목 등록

영문 소문자·숫자·밑줄·하이픈, 최대 80자

과목코드과목명관리

분반 목록은 등록된 수강 명단을 기준으로 표시합니다. CSV는 화면의 분반 선택과 관계없이 파일에 적힌 분반으로 등록합니다.

학생 직접 등록

학번·이름을 수정하면 이 학생의 다른 과목 명단과 가입 정보에도 반영됩니다. 분반은 선택한 수강 행에만 반영됩니다.

CSV 일괄 등록

첫 행: 과목코드,학번,이름,분반
한 파일에 여러 과목을 작성할 수 있습니다. 분반은 1, 2, 3처럼 입력하며 생략할 수 있습니다. 양식의 학생 정보와 분반은 예시이므로 실제 명단으로 바꿔 주세요. Excel에서 CSV UTF-8로 저장해 주세요. 학번과 분반은 앞자리 0이 사라지지 않도록 텍스트로 입력합니다.

CSV 양식 다운로드 (과목코드 포함)

    과목코드 열에 적힌 과목에 등록합니다. 과목코드가 없는 기존 양식만 위에서 선택한 과목에 등록합니다. 같은 과목·분반·학번은 중복 등록하지 않고 건너뜁니다. 분반 변경은 명단의 수정 버튼을 사용해 주세요. CSV에 없는 기존 학생은 유지합니다.
