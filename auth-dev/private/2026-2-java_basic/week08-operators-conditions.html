1. 산술 연산자

연산자는 계산이나 비교를 수행하는 기호입니다. 산술 연산자는 덧셈, 뺄셈과 같은 계산에 사용합니다.

연산자 의미 예 결과
+ 덧셈 7 + 2 9
- 뺄셈 7 - 2 5
* 곱셈 7 * 2 14
/ 나눗셈 7 / 2 3
% 나머지 7 % 2 1

정수끼리 나누면 소수 부분을 버린 정수 결과가 나옵니다. 실수 결과가 필요하면 계산할 때 한쪽 값을 실수로 만듭니다.

파일 이름은 ArithmeticExample.java로 저장합니다.

public class ArithmeticExample {
    public static void main(String[] args) {
        int x = 7;
        int y = 2;

        System.out.printf("합: %d%n", x + y);
        System.out.printf("몫: %d%n", x / y);
        System.out.printf("나머지: %d%n", x % y);
        System.out.printf("실수 나눗셈: %.1f%n", (double) x / y);
    }
}

예상 실행 결과:

합: 9
몫: 3
나머지: 1
실수 나눗셈: 3.5

⚠️ 주의: double result = 7 / 2;는 정수 나눗셈 후 저장하므로 결과가 3.0입니다. 정수 나눗셈과 나머지 연산에서 나누는 수가 0이면 오류가 발생합니다.

곱셈·나눗셈·나머지는 덧셈·뺄셈보다 먼저 계산합니다. 계산 순서를 명확하게 하려면 괄호를 사용합니다.

식 결과
2 + 3 * 4 14
(2 + 3) * 4 20

2. 비교 연산자

두 값을 비교한 결과는 boolean 값인 true 또는 false입니다.

연산자 의미 예 결과
> 크다 7 > 2 true
>= 크거나 같다 7 >= 7 true
< 작다 7 < 2 false
<= 작거나 같다 7 <= 7 true
== 같다 7 == 2 false
!= 다르다 7 != 2 true

📌 score = 60은 변수에 값을 저장합니다. score == 60은 값이 같은지 비교합니다. 이 표의 예제는 정수 비교이며, 문자열 내용 비교는 다음 장에서 다룹니다.

3. if: 조건을 만족할 때 실행하기

조건문은 조건에 따라 실행할 코드를 선택하는 문장입니다. if의 괄호 안에는 참 또는 거짓이 되는 식을 적습니다. 참이면 중괄호 { } 안의 코드를 실행합니다.

파일 이름은 PassCheck.java로 저장합니다.

import java.util.Scanner;

public class PassCheck {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("점수를 입력하세요: ");
        int score = scanner.nextInt();

        if (score >= 60) {
            System.out.printf("합격입니다.%n");
        }
        System.out.printf("판정을 마쳤습니다.%n");

        scanner.close();
    }
}

예상 실행 화면:

점수를 입력하세요: 75
합격입니다.
판정을 마쳤습니다.

50을 입력하면 합격입니다.는 출력하지 않습니다. 중괄호 밖의 판정을 마쳤습니다.는 조건과 관계없이 출력합니다. 이 예제는 0~100 사이의 정수가 입력된다고 가정합니다.

⚠️ 주의: if (score >= 60) 바로 뒤에 세미콜론(;)을 붙이지 않습니다. 실행할 코드는 중괄호 안에 작성합니다.

4. if ~ else: 두 경우로 나누기

else에는 조건이 거짓일 때 실행할 코드를 적습니다. 앞 예제의 if 부분을 다음 코드로 교체합니다.

if (score >= 60) {
    System.out.printf("합격입니다.%n");
} else {
    System.out.printf("불합격입니다.%n");
}
입력한 점수 선택되는 출력
60 합격입니다.
59 불합격입니다.

두 중괄호 영역 중 하나만 실행합니다.

5. else if: 여러 경우로 나누기

else if는 앞의 조건이 거짓일 때 다음 조건을 검사합니다. 하나의 연결된 조건문에서는 처음 참이 된 조건의 코드만 실행합니다.

앞 예제의 조건문을 다음 코드로 교체합니다. 입력 점수는 0~100 사이라고 가정합니다.

if (score >= 90) {
    System.out.printf("A등급%n");
} else if (score >= 80) {
    System.out.printf("B등급%n");
} else if (score >= 70) {
    System.out.printf("C등급%n");
} else {
    System.out.printf("재학습이 필요합니다.%n");
}

85를 입력하면 첫 조건은 거짓이고 두 번째 조건은 참이므로 B등급을 출력합니다. 이때 score >= 70은 더 검사하지 않습니다.

⚠️ 주의: score >= 70부터 검사하면 95도 그 조건에 먼저 해당합니다. 이 예제에서는 높은 점수부터 검사해야 합니다.

6. 논리 연산자: 조건 결합하기

논리 연산자는 조건 여러 개를 결합하거나 참과 거짓을 뒤집습니다.

연산자 의미 예
&& 두 조건이 모두 참이면 참 score >= 0 && score <= 100
`\ \ ` 하나 이상의 조건이 참이면 참 `score < 0 \ \ score > 100`
! 참과 거짓을 반대로 바꿈 !isValid

파일 이름은 ScoreRangeCheck.java로 저장합니다.

import java.util.Scanner;

public class ScoreRangeCheck {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("점수를 입력하세요: ");
        int score = scanner.nextInt();
        boolean isValid = score >= 0 && score <= 100;

        if (!isValid) {
            System.out.printf("점수는 0~100 사이여야 합니다.%n");
        } else {
            System.out.printf("입력 가능한 점수입니다.%n");
        }

        scanner.close();
    }
}

예상 실행 화면:

점수를 입력하세요: 105
점수는 0~100 사이여야 합니다.

📌 Java에서는 0 <= score <= 100으로 작성하지 않습니다. score >= 0 && score <= 100처럼 비교식을 각각 적습니다.

7. 연습: 양수·음수·0 판정

  • 파일 이름은 NumberSignCheck.java로 저장합니다.
  • Scanner로 정수 하나를 입력받습니다.
  • if, else if, else를 사용해 양수, 음수, 0 중 하나를 출력합니다.
  • 입력값은 int 범위의 정수라고 가정합니다.

예상 실행 화면:

정수를 입력하세요: -3
음수입니다.

✅ 확인할 것:

  • 5를 입력하면 양수입니다.가 출력됩니다.
  • -3을 입력하면 음수입니다.가 출력됩니다.
  • 0을 입력하면 0입니다.가 출력됩니다.
  • 한 번 실행할 때 판정 결과는 하나만 출력됩니다.
