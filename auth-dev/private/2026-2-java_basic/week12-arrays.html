1. 배열 만들기와 인덱스

배열은 같은 자료형의 값을 정해진 개수만큼 담는 객체입니다. 각 값을 원소, 원소의 위치를 인덱스라고 합니다. 인덱스는 0부터 시작합니다.

파일 이름은 ArrayBasics.java로 저장합니다.

public class ArrayBasics {
    public static void main(String[] args) {
        int[] scores = {80, 95, 60};
        System.out.printf("첫 점수: %d%n", scores[0]);
        System.out.printf("배열 길이: %d%n", scores.length);

        scores[1] = 100;
        for (int i = 0; i < scores.length; i++) {
            System.out.printf("%d번 점수: %d%n", i + 1, scores[i]);
        }
    }
}

예상 실행 결과:

첫 점수: 80
배열 길이: 3
1번 점수: 80
2번 점수: 100
3번 점수: 60
표현 의미
int[] scores 정수 배열을 가리킬 변수 선언
{80, 95, 60} 초기 원소 세 개로 배열 생성
scores[1] 두 번째 원소
scores.length 배열의 길이. 괄호를 붙이지 않음

⚠️ 길이가 3이면 인덱스는 0~2입니다. scores[3]에 접근하면 ArrayIndexOutOfBoundsException이라는 범위 오류가 발생합니다. 반복 조건은 i <= scores.length가 아니라 i < scores.length입니다.

2. 공간부터 만들고 값 저장하기

new int[5]는 정수 다섯 개를 담을 배열을 만듭니다. 처음 원소는 모두 0입니다. 만들어진 배열의 길이는 바뀌지 않습니다.

파일 이름은 ScoreArrayInput.java로 저장합니다.

import java.util.Scanner;

public class ScoreArrayInput {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int[] scores = new int[5];
        int count = 0;

        while (count < scores.length) {
            System.out.print("점수 입력 (0~100, -1: 종료): ");
            int score = scanner.nextInt();
            if (score == -1) {
                break;
            }
            if (score < 0 || score > 100) {
                System.out.printf("범위를 확인하세요.%n");
                continue;
            }
            scores[count] = score;
            count++;
        }

        System.out.printf("저장한 점수: %d개%n", count);
        for (int i = 0; i < count; i++) {
            System.out.printf("%d번: %d%n", i + 1, scores[i]);
        }
        scanner.close();
    }
}

예상 실행 화면:

점수 입력 (0~100, -1: 종료): 80
점수 입력 (0~100, -1: 종료): 0
점수 입력 (0~100, -1: 종료): -1
저장한 점수: 2개
1번: 80
2번: 0

📌 scores.length는 저장 공간 5개, count는 실제 점수 2개입니다. 나머지 원소의 초기값 0을 실제 입력한 0점과 혼동하지 않습니다. 배열이 가득 차면 입력 반복은 끝납니다.

3. 배열에서 통계 구하기

이미 저장된 배열이라면 입력 없이 반복해서 계산할 수 있습니다. 파일 이름은 ArrayStatistics.java로 저장합니다.

public class ArrayStatistics {
    public static void main(String[] args) {
        int[] scores = {80, 95, 60, 0};

        if (scores.length == 0) {
            System.out.printf("점수가 없습니다.%n");
        } else {
            int total = 0;
            int min = scores[0];
            int max = scores[0];
            int passed = 0;

            for (int i = 0; i < scores.length; i++) {
                total += scores[i];
                if (scores[i] < min) {
                    min = scores[i];
                }
                if (scores[i] > max) {
                    max = scores[i];
                }
                if (scores[i] >= 60) {
                    passed++;
                }
            }
            double average = (double) total / scores.length;
            System.out.printf("합계: %d%n평균: %.2f%n", total, average);
            System.out.printf("최저점: %d%n", min);
            System.out.printf("최고점: %d%n합격자: %d명%n", max, passed);
        }
    }
}

예상 실행 결과:

합계: 235
평균: 58.75
최저점: 0
최고점: 95
합격자: 3명

최솟값과 최댓값은 모두 첫 원소로 시작합니다. 현재 값보다 작으면 min, 크면 max를 바꿉니다. 같은 반복문에서 합계와 최솟값·최댓값을 함께 구할 수 있습니다. 최솟값을 무조건 0으로 시작하면 {80, 95, 60}처럼 0점이 없는 배열에서도 최저점이 0으로 남으므로 주의합니다. 첫 원소를 읽기 전에 빈 배열인지 검사합니다. scores를 {}로 바꾸면 점수가 없습니다.를 출력합니다.

3.1 문제: 배열의 평균 구하기

평균은 모든 값의 합계를 값의 개수로 나눈 것입니다. 앞의 예제를 참고해 점수 배열의 평균을 직접 구해 봅니다.

파일 이름은 AverageScore.java로 저장합니다.

  • int[] scores = {80, 95, 60, 0, 70};으로 시작합니다.
  • 배열의 모든 원소가 실제 점수이며, 각 점수는 0~100입니다.
  • 반복문으로 합계를 구하고, 원소 개수는 scores.length를 사용합니다.
  • 평균은 double로 구하고 %.2f로 출력합니다.
  • 빈 배열이면 점수가 없습니다.를 출력하고 나누기를 하지 않습니다.
계산 결과
합계 80 + 95 + 60 + 0 + 70 = 305
개수 5
평균 305 / 5 = 61.0

예상 실행 결과:

평균: 61.00

💡 힌트: double average = total / scores.length;는 정수끼리 나누는 식입니다. (double) total처럼 나누기 전에 한쪽을 실수로 바꿉니다.

확인 문제: {80, 95}의 평균은 87.50, {0}의 평균은 0.00이어야 합니다. 빈 배열에서는 계산 결과 대신 안내만 출력합니다.

3.2 문제: 분산과 표준편차 구하기

평균만으로는 점수들이 얼마나 흩어져 있는지 알기 어렵습니다. {80, 80, 80}과 {60, 80, 100}은 평균이 모두 80이지만, 두 번째 배열의 점수 차이가 더 큽니다.

용어 뜻
편차 각 점수에서 평균을 뺀 값
분산 편차를 각각 제곱한 뒤 구한 평균
표준편차 분산의 제곱근. 점수와 같은 단위로 흩어진 정도를 나타냄

편차에는 양수와 음수가 있어 단순히 더하면 서로 상쇄됩니다. 따라서 각 편차를 제곱해 평균을 구합니다. 제곱근은 어떤 수를 제곱했을 때 주어진 값이 되는 수이며, 여기서는 0 이상의 값을 사용합니다.

📌 이번 문제는 배열의 점수 전체를 대상으로 하는 모분산·모표준편차를 구합니다. 편차 제곱의 합을 원소 개수 N으로 나눕니다. 일부 자료로 전체의 분산을 추정할 때 쓰는 N - 1 기준의 표본분산과 구분합니다.

파일 이름은 ScoreSpread.java로 저장합니다. 3.1과 같은 배열 {80, 95, 60, 0, 70}을 사용합니다.

  1. 첫 번째 반복문으로 합계를 구하고 실수 평균을 계산합니다.
  2. 두 번째 반복문에서 각 점수의 편차를 구합니다.
  3. diff * diff로 편차의 제곱을 누적합니다.
  4. 편차 제곱의 합을 개수로 나누어 분산을 구합니다.
  5. 분산의 제곱근으로 표준편차를 구합니다.
점수 편차: 점수 - 평균 61 편차의 제곱
80 19 361
95 34 1156
60 -1 1
0 -61 3721
70 9 81
합계 0 5320

분산은 5320 / 5 = 1064.0이고, 표준편차는 약 32.62입니다. 평균·편차·편차 제곱의 합·분산·표준편차를 저장할 변수는 double로 둡니다.

Java에서 제곱근은 Math.sqrt()로 구합니다. Math는 기본 제공 클래스이므로 별도 import 없이 사용합니다. 분산을 계산한 뒤 다음 문장을 사용할 수 있습니다.

double standardDeviation = Math.sqrt(variance);

예상 실행 결과:

평균: 61.00
분산: 1064.00
표준편차: 32.62

⚠️ 평균을 구하려고 입력 배열을 정렬할 필요는 없습니다. 평균은 각 점수의 합계, 분산은 평균과 각 점수의 차이를 이용해 계산합니다. 출력할 때만 소수 자릿수를 맞추고, 계산 중간의 평균을 정수로 바꾸거나 반올림하지 않습니다.

확인할 배열 평균 모분산 모표준편차
{80, 95, 60, 0, 70} 61.00 1064.00 32.62
{80, 80, 80} 80.00 0.00 0.00
{60, 80, 100} 80.00 266.67 16.33
{0} 0.00 0.00 0.00
{} 계산 안 함 계산 안 함 점수가 없다는 안내

빈 배열에서는 평균·분산·표준편차를 모두 계산하지 않습니다. 원소가 하나뿐이면 모분산과 모표준편차는 0입니다.

3.3 문제: 정렬해서 중간값 구하기

정렬은 값을 일정한 순서로 나열하는 것입니다. 작은 값부터 나열하면 오름차순, 큰 값부터 나열하면 내림차순입니다. 중간값(중앙값, median)은 정렬한 자료의 가운데 값입니다. 평균과는 다릅니다.

구분 점수의 순서
원래 배열 80, 95, 60, 0, 70
오름차순 정렬 0, 60, 70, 80, 95
가운데 값 세 번째 값인 70

문제: 점수 배열을 오름차순으로 정렬한 뒤 중간값을 출력합니다. 파일 이름은 MedianScore.java로 저장합니다.

  • int[] scores = {80, 95, 60, 0, 70};으로 시작합니다.
  • 점수는 0~100이며, 기본 문제에서는 원소가 한 개 이상이고 개수가 홀수라고 가정합니다.
  • 배열의 길이가 달라져도 가운데 인덱스를 계산해 찾도록 작성합니다.
  • 배열이 비어 있으면 점수가 없습니다.를 출력하고 원소에 접근하지 않습니다.

정렬에는 Java 표준 라이브러리의 java.util.Arrays.sort()를 사용합니다. Arrays는 배열을 다루는 도우미 클래스이고, sort()는 원소를 오름차순으로 정렬하는 메서드입니다. 다음 코드는 scores 배열을 만든 뒤 main 안에서 사용합니다.

java.util.Arrays.sort(scores);

이 메서드는 원래 배열의 순서를 직접 바꿉니다. 새 배열을 반환하지 않으므로 scores = java.util.Arrays.sort(scores);처럼 대입하지 않습니다. 이 문제에서는 표준 정렬 기능으로 정렬 전후의 원소 순서와 인덱스를 확인합니다. 3.4에서는 같은 작업을 반복문으로 직접 구현해 비교합니다.

예상 실행 결과:

중간값: 70

💡 힌트: 인덱스는 0부터 시작합니다. 원소 5개의 가운데는 인덱스 2, 원소 3개의 가운데는 인덱스 1입니다. 배열 길이를 2로 나눈 정수 몫과 연결해 봅니다.

확인할 배열 정렬 후 예상 중간값
{80, 95, 60, 0, 70} {0, 60, 70, 80, 95} 70
{90, 30, 60} {30, 60, 90} 60
{80, 80, 60} {60, 80, 80} 80
{0} {0} 0
{} 빈 배열 점수가 없다는 안내

⚠️ 정렬하지 않고 원래 배열의 가운데 원소를 읽으면 첫 예제에서는 60이 나옵니다. 입력 순서의 가운데와 정렬 후의 중간값을 구분합니다.

확장 문제: 원소 개수가 짝수이면 가운데 두 값의 평균을 출력하도록 바꿉니다. 예를 들어 {0, 59, 80, 100}의 중간값은 69.5입니다. 정수 나눗셈으로 소수 부분이 사라지지 않게 확인합니다.

3.4 예제: 반복문으로 통계 함께 구하기

앞의 평균·분산·표준편차·중간값을 하나의 프로그램에서 구해 봅니다. 최솟값과 최댓값도 함께 출력합니다. 배열의 모든 원소는 실제 점수이며, 점수 범위는 0~100입니다.

구할 값 계산 방법 반복문의 역할
합계·최솟값·최댓값 점수를 더하고 현재 최솟값·최댓값과 비교 첫 번째 반복에서 함께 처리
평균 합계 / 개수 첫 번째 반복이 끝나면 계산
모분산 편차 제곱의 합 / 개수 평균을 구한 뒤 두 번째 반복으로 누적
모표준편차 모분산의 제곱근 누적한 분산에 Math.sqrt() 적용
중간값 정렬한 배열의 가운데 값 중첩 반복문으로 정렬한 뒤 가운데 인덱스로 접근

분산을 구할 때는 평균이 먼저 필요하므로 배열을 한 번 더 읽습니다. 표준편차는 이 반복문으로 구한 분산에 Math.sqrt()를 적용합니다. 제곱근 계산 자체를 반복문으로 구현하는 예제는 아닙니다.

중간값을 위한 정렬에는 선택 정렬을 사용합니다. 아직 정렬하지 않은 구간에서 가장 작은 값의 위치를 찾아, 그 구간의 맨 앞 값과 자리를 바꾸는 방법입니다.

단계 하는 일 배열의 상태
시작 정렬 전 80, 95, 60, 0, 70
i = 0 전체에서 최솟값 0을 찾아 첫 원소와 교환 0, 95, 60, 80, 70
i = 1 뒤의 네 값 중 최솟값 60을 찾아 두 번째 원소와 교환 0, 60, 95, 80, 70
i = 2 뒤의 세 값 중 최솟값 70을 찾아 세 번째 원소와 교환 0, 60, 70, 80, 95
i = 3 남은 두 값 중 80이 이미 앞에 있으므로 유지 0, 60, 70, 80, 95

원래 점수의 입력 순서를 보존하려고 sorted 배열을 새로 만들고, 첫 번째 반복에서 값을 하나씩 복사합니다. int[] sorted = scores;는 같은 배열을 가리키므로 복사가 아닙니다.

파일 이름은 LoopStatistics.java로 저장합니다.

public class LoopStatistics {
    public static void main(String[] args) {
        int[] scores = {80, 95, 60, 0, 70};
        int count = scores.length;

        if (count == 0) {
            System.out.printf("점수가 없습니다.%n");
        } else {
            int total = 0;
            int min = scores[0];
            int max = scores[0];
            int[] sorted = new int[count];

            // 1. 합계·최솟값·최댓값을 구하고 정렬용 배열에 복사
            for (int i = 0; i < count; i++) {
                total += scores[i];
                if (scores[i] < min) {
                    min = scores[i];
                }
                if (scores[i] > max) {
                    max = scores[i];
                }
                sorted[i] = scores[i];
            }
            double average = (double) total / count;

            // 2. 평균과의 차이를 제곱하여 누적
            double squaredSum = 0;
            for (int i = 0; i < count; i++) {
                double diff = scores[i] - average;
                squaredSum += diff * diff;
            }
            double variance = squaredSum / count;
            double standardDeviation = Math.sqrt(variance);

            // 3. 선택 정렬: 남은 구간의 최솟값을 앞으로 이동
            for (int i = 0; i < count - 1; i++) {
                int minIndex = i;
                for (int j = i + 1; j < count; j++) {
                    if (sorted[j] < sorted[minIndex]) {
                        minIndex = j;
                    }
                }
                int temp = sorted[i];
                sorted[i] = sorted[minIndex];
                sorted[minIndex] = temp;
            }

            // 4. 홀수 개이면 가운데 값, 짝수 개이면 가운데 두 값의 평균
            int middle = count / 2;
            double median;
            if (count % 2 == 1) {
                median = sorted[middle];
            } else {
                median = (sorted[middle - 1] + sorted[middle]) / 2.0;
            }

            System.out.printf("합계: %d%n평균: %.2f%n", total, average);
            System.out.printf("최저점: %d%n최고점: %d%n", min, max);
            System.out.printf("분산: %.2f%n", variance);
            System.out.printf("표준편차: %.2f%n", standardDeviation);
            System.out.printf("중간값: %.2f%n", median);
        }
    }
}

예상 실행 결과:

합계: 305
평균: 61.00
최저점: 0
최고점: 95
분산: 1064.00
표준편차: 32.62
중간값: 70.00

min은 가장 작은 점수, minIndex는 정렬 중 남은 구간에서 가장 작은 값의 위치입니다. 안쪽 반복문의 j가 나머지 원소를 확인하고, 바깥 반복문의 i가 이번에 채울 위치를 정합니다. temp는 두 원소를 바꿀 때 먼저 저장한 값이 덮어써지지 않도록 잠시 보관합니다. 마지막 원소는 앞의 자리가 정해지면 자동으로 정해지므로 i < count - 1까지만 반복합니다.

중간 인덱스는 정수 나눗셈 count / 2로 구합니다. 원소가 5개이면 인덱스 2의 값을 읽고, 4개이면 인덱스 1과 2의 평균을 구합니다. 짝수일 때는 / 2.0을 사용해 69.5 같은 소수 부분을 유지합니다.

비교 Arrays.sort() 사용 반복문으로 선택 정렬
정렬 코드 java.util.Arrays.sort(sorted); 한 문장 가장 작은 위치를 찾고 두 값을 바꾸는 중첩 반복문
학습할 내용 정렬 결과를 이용해 중간값 구하기 비교·인덱스·교환으로 정렬 과정을 직접 이해하기
원래 순서 보존 별도 배열에 복사한 뒤 정렬 위 예제처럼 별도 배열에 복사한 뒤 정렬
계산 결과 같은 입력이면 같은 중간값 같은 입력이면 같은 중간값

위 코드의 3번 중첩 반복문 전체를 java.util.Arrays.sort(sorted);로 바꾸어 결과를 비교해 봅니다. 평균·분산·표준편차 계산은 그대로 둡니다. 실제 작업에서는 표준 정렬 기능을 사용하고, 선택 정렬은 반복문의 동작을 이해하는 데 활용합니다.

📌 평균과 중간값은 다른 기준입니다. 이 배열의 평균은 61.00, 중간값은 70.00입니다. 분산과 표준편차는 크기순 가운데가 아니라 평균에서 얼마나 떨어져 있는지로 계산합니다.

확인 문제:

  • {80, 95, 60}: 최저점은 60이어야 합니다. min을 0으로 시작하면 이 경우를 틀립니다.
  • {80, 80, 80}: 최저점·최고점·평균·중간값은 모두 80이고, 분산·표준편차는 0입니다.
  • {0, 59, 80, 100}: 중간값은 69.50입니다. 짝수 개일 때 가운데 두 값을 사용했는지 확인합니다.
  • {0}: 최저점·최고점·평균·분산·표준편차·중간값이 모두 0입니다.
  • {}: 점수가 없습니다.만 출력하고, 원소 접근과 나누기를 모두 건너뜁니다.

4. 인덱스가 필요 없는 반복과 값 검색

앞의 통계 계산에서는 scores[i]의 값을 더했습니다. 그런데 모든 점수를 출력하거나 더하기만 한다면, 그 값이 몇 번째 원소인지 알 필요는 없습니다. 값이 필요한 작업인지, 위치까지 필요한 작업인지에 따라 반복문을 선택할 수 있습니다.

4.1 값만 읽을 때: 향상된 for문

일반 for에서는 인덱스를 직접 관리합니다. 다음 코드는 scores 배열이 있는 main 안에서 사용합니다.

for (int i = 0; i < scores.length; i++) {
    System.out.printf("%d%n", scores[i]);
}

출력에 필요한 것은 i 자체가 아니라 scores[i]의 점수입니다. 이럴 때는 향상된 for문(enhanced for, for-each)으로 각 원소의 값을 바로 받아 사용할 수 있습니다.

파일 이름은 ReadScores.java로 저장합니다.

public class ReadScores {
    public static void main(String[] args) {
        int[] scores = {80, 95, 60, 80};
        int total = 0;

        for (int score : scores) {
            System.out.printf("%d%n", score);
            total += score;
        }
        System.out.printf("합계: %d%n", total);
    }
}

예상 실행 결과:

80
95
60
80
합계: 315

for (int score : scores)는 “scores의 원소를 처음부터 하나씩 score에 받아 반복한다”라고 읽습니다. score에는 차례대로 80, 95, 60, 80이 들어갑니다.

좋은 점 이유
값 처리 의도가 잘 보임 원소의 값에 어떤 작업을 하는지 바로 읽을 수 있음
인덱스 관리가 줄어듦 시작값·끝 조건·증가식을 직접 작성하지 않아도 됨
반복 범위 실수가 줄어듦 직접 i <= scores.length처럼 잘못 쓰는 일을 피할 수 있음

📌 전체 점수의 출력·합계·조건을 만족하는 개수 세기처럼 위치를 몰라도 되는 작업에 어울립니다.

4.2 위치가 필요할 때: 인덱스 반복문

향상된 for문이 모든 반복을 대신하는 것은 아닙니다. int score에는 현재 정수 원소의 값이 복사되므로, score = 100;으로 바꿔도 원래 정수 배열의 원소는 바뀌지 않습니다. 배열의 점수를 수정하려면 scores[i] = 100;처럼 위치를 지정합니다.

하고 싶은 일 선택할 반복문 이유
전체 점수 출력·합계 향상된 for문 원소의 값만 필요
특정 점수가 있는지만 확인 향상된 for문 사용 가능 참·거짓 결과만 필요
특정 점수가 처음 나온 위치 기록 인덱스 for문 발견한 인덱스가 필요
배열의 특정 원소 수정 인덱스 for문 scores[i]에 새 값을 저장
실제 입력한 count개만 처리 i < count인 for문 배열 전체가 아닌 사용 중인 구간만 필요

⚠️ new int[5]에 점수 두 개만 저장했어도 향상된 for문은 원소 다섯 개를 모두 읽습니다. 남은 초기값 0까지 점수로 계산하지 않도록, 이 경우에는 count를 사용하는 인덱스 반복문을 선택합니다.

4.3 값 검색: 존재 여부와 위치 구분하기

“80점이 있는가?”와 “80점이 몇 번째에 있는가?”는 필요한 결과가 다릅니다. 존재 여부만 필요하면 위치를 기록하지 않고 다음처럼 확인할 수 있습니다. 아래 코드는 scores 배열이 있는 main 안에서 사용합니다.

int target = 80;
boolean exists = false;

for (int score : scores) {
    if (score == target) {
        exists = true;
        break;
    }
}
System.out.println(exists);

{80, 95, 60, 80}에서는 true를 출력합니다. 찾는 즉시 break하므로 나머지 원소를 불필요하게 검사하지 않습니다.

반면 발견한 위치를 출력하거나 그 자리의 점수를 바꾸려면 인덱스가 필요합니다. 다음 예제는 앞에서부터 하나씩 비교하는 순차 검색으로 첫 위치를 찾습니다. 정렬되지 않은 배열에도 사용할 수 있습니다.

파일 이름은 ScoreSearch.java로 저장합니다.

public class ScoreSearch {
    public static void main(String[] args) {
        int[] scores = {80, 95, 60, 80};
        int target = 80;
        int found = -1;

        for (int i = 0; i < scores.length; i++) {
            if (scores[i] == target) {
                found = i;
                break;
            }
        }
        if (found == -1) {
            System.out.printf("점수를 찾지 못했습니다.%n");
        } else {
            System.out.printf("첫 위치: %d번%n", found + 1);
        }
    }
}

예상 출력은 첫 위치: 1번입니다.

코드 필요한 이유
int found = -1 유효한 인덱스가 아닌 값으로 “아직 못 찾음”을 표시
found = i 찾은 값의 위치를 나중에 사용할 수 있도록 기록
break 첫 위치를 찾았으므로 검색 종료. 뒤의 같은 값으로 덮어쓰지 않음
found == -1 검사 끝까지 못 찾은 경우와 첫 인덱스 0에서 찾은 경우를 구분
found + 1 0부터 시작하는 인덱스를 사람이 읽는 1번·2번 위치로 표시
target을 바꿔 확인하기 예상 결과
80 첫 위치 1번. 네 번째의 80점까지 찾지는 않음
95 첫 위치 2번
60 첫 위치 3번
70 찾지 못했다는 안내

⚠️ 못 찾은 경우의 found는 -1이므로, 확인 없이 scores[found]에 접근하면 범위 오류가 발생합니다. 앞 절의 중간값 문제와 달리 이 검색을 위해 정렬할 필요는 없습니다. 배열을 정렬하면 원래 입력 순서가 바뀌므로, 정렬 후의 위치를 원래 입력 위치라고 해석하지 않습니다.

✅ 선택 기준: “값만 처리하는가?”이면 향상된 for문, “어느 위치인지·어느 범위인지 필요한가?”이면 인덱스 반복문을 먼저 검토합니다.

5.1 배열 비교도 ==를 주의하기

6-1의 문자열 비교처럼 배열에서도 ==는 같은 객체인지 확인합니다. 일차원 정수 배열의 내용 비교에는 java.util.Arrays.equals(a, b)를 사용합니다. Arrays는 Java 표준 라이브러리의 배열 도우미 클래스입니다.

int[] a = {1, 2};
int[] b = {1, 2};
System.out.println(a == b);                       // false
System.out.println(java.util.Arrays.equals(a, b)); // true

이 코드는 main 안에 넣어 실행합니다. int[] b = a;는 새 배열을 복사하지 않고 같은 배열을 가리키게 합니다.

7. 메서드의 입력·처리·결과

메서드(method)는 이름을 붙여 묶어 둔 실행 코드입니다. System.out.printf()와 scanner.nextInt()도 메서드 호출입니다. 이제 직접 메서드를 정의합니다.

용어 의미 예
선언 메서드의 동작을 정의 static int add(int a, int b) { ... }
호출 정의한 동작을 실행 add(3, 4)
매개변수 전달받은 값을 사용하는 변수 선언의 a, b
인수 호출할 때 전달하는 값 호출의 3, 4
반환값 호출한 곳으로 돌려주는 결과 return a + b;의 계산값

파일 이름은 MethodBasics.java로 저장합니다.

public class MethodBasics {
    static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        int result = add(3, 4);
        System.out.printf("결과: %d%n", result);
    }
}

예상 출력은 결과: 7입니다. 프로그램은 main에서 시작하고, add(3, 4)를 만나면 add를 실행한 뒤 돌아옵니다. return은 결과를 돌려주면서 현재 메서드를 끝냅니다.

💡 참고: 이 장에서는 main과 같은 클래스에 static 메서드를 만듭니다. static 메서드는 그 클래스의 객체를 만들지 않고 호출할 수 있습니다. 객체마다 다르게 동작하는 메서드는 다음 클래스 교안에서 배웁니다.

⚠️ 새 메서드는 main의 중괄호 밖, 클래스의 중괄호 안에 작성합니다. Java에서는 메서드 안에 다른 메서드를 선언할 수 없습니다.

8. 반환값이 없는 void 메서드

void는 돌려주는 값이 없다는 뜻입니다. 화면 출력만 하는 동작은 반환값이 없어도 됩니다. 다음 선언은 MethodBasics 클래스 안에서 main 밖에 추가할 수 있습니다.

static void printTitle() {
    System.out.printf("성적 보고서%n");
}

main에서 printTitle();로 호출합니다. int result = printTitle();처럼 반환값을 저장할 수는 없습니다. 화면에 출력하는 것과 값을 반환하는 것은 서로 다릅니다.

9. 배열을 전달해 통계 구하기

8-1의 점수 통계를 메서드로 분리합니다. 배열에 유효한 점수만 들어 있다고 가정합니다. 비어 있을 때는 평균을 계산하지 않습니다.

파일 이름은 ScoreMethods.java로 저장합니다.

public class ScoreMethods {
    static boolean isValidScore(int score) {
        return score >= 0 && score <= 100;
    }

    static int sum(int[] scores) {
        int total = 0;
        for (int score : scores) {
            total += score;
        }
        return total;
    }

    static String grade(int score) {
        if (!isValidScore(score)) {
            return "범위 오류";
        }
        if (score >= 90) {
            return "A";
        } else if (score >= 80) {
            return "B";
        } else if (score >= 70) {
            return "C";
        } else {
            return "재학습";
        }
    }

    static void printReport(int[] scores) {
        if (scores.length == 0) {
            System.out.printf("점수가 없습니다.%n");
            return;
        }
        for (int i = 0; i < scores.length; i++) {
            System.out.printf("%d번: %d점, %s%n",
                    i + 1, scores[i], grade(scores[i]));
        }
        int total = sum(scores);
        double average = (double) total / scores.length;
        System.out.printf("합계: %d%n평균: %.2f%n", total, average);
    }

    public static void main(String[] args) {
        int[] scores = {90, 80, 60};
        printReport(scores);
    }
}

예상 실행 결과:

1번: 90점, A
2번: 80점, B
3번: 60점, 재학습
합계: 230
평균: 76.67
메서드 받는 값 반환형 역할
isValidScore 정수 하나 boolean 점수 범위 검사
sum 정수 배열 int 합계 계산
grade 정수 하나 String 등급 문자열 반환
printReport 정수 배열 void 보고서 출력

return;처럼 값 없이 쓰면 void 메서드를 바로 끝냅니다. 앞의 return "A";는 결과를 반환하고 끝냅니다. break는 반복문이나 switch를 끝내므로 역할을 구분합니다.

10. 지역변수와 값 전달

지역변수는 메서드나 블록 안에 선언한 변수입니다. 서로 다른 메서드에 같은 이름의 변수가 있어도 각각 별개입니다. Java는 호출할 때 값을 복사해서 전달합니다. 배열은 배열을 가리키는 참조값이 복사됩니다.

파일 이름은 ArgumentCheck.java로 저장합니다.

public class ArgumentCheck {
    static void changeNumber(int number) {
        number = 100;
    }

    static void changeFirst(int[] numbers) {
        numbers[0] = 100;
    }

    public static void main(String[] args) {
        int number = 5;
        int[] numbers = {5};
        changeNumber(number);
        changeFirst(numbers);
        System.out.printf("정수: %d%n", number);
        System.out.printf("배열 원소: %d%n", numbers[0]);
    }
}

예상 실행 결과:

정수: 5
배열 원소: 100

changeFirst의 매개변수와 호출한 곳의 배열 변수가 같은 배열을 가리켜 원소 변경이 보입니다. 반대로 매개변수에 numbers = new int[] {100};을 대입하면 매개변수만 새 배열을 가리키므로 호출한 곳의 배열 변수는 바뀌지 않습니다.

📌 배열이 바뀔 수 있다는 이유로 Java가 참조에 의한 전달을 한다고 설명하지 않습니다. 참조값 자체를 복사해서 전달하는 방식입니다.

함수는 다른 언어에서 이름을 붙인 실행 단위를 부르는 일반적인 표현입니다. Java에서는 클래스 안의 메서드로 작성합니다.
