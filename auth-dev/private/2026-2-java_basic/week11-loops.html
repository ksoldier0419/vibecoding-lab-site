앞에서는 조건에 따라 실행할 코드를 선택했습니다. 이번에는 같은 작업을 여러 번 실행하는 반복문을 배웁니다.

  • for로 정해진 횟수만큼 반복합니다.
  • while과 do ~ while로 조건에 따라 반복합니다.
  • 반복하면서 합계를 구하고, break와 continue로 흐름을 조절합니다.

1. for: 정해진 횟수만큼 반복하기

for는 시작값, 반복 조건, 값의 변화를 한곳에 작성합니다. 먼저 1부터 5까지 출력해 봅니다.

파일 이름은 CountFor.java로 저장합니다.

public class CountFor {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.printf("%d%n", i);
        }
    }
}

예상 실행 결과:

1
2
3
4
5

1.1 코드 살펴보기

부분 역할
int i = 1 반복 시작 전에 한 번 실행합니다.
i <= 5 매번 반복하기 전에 검사합니다. 참이면 반복합니다.
i++ 중괄호 안의 코드 실행 후 i를 1 증가시킵니다.
{ ... } 반복해서 실행할 코드입니다.

i++는 이 예제에서 i = i + 1과 같은 역할을 합니다. i--는 값을 1 줄입니다.

실행 순서는 다음과 같습니다.

  1. i를 1로 초기화합니다.
  2. i <= 5를 검사합니다.
  3. 참이면 i를 출력합니다.
  4. i++로 값을 늘리고 2번으로 돌아갑니다.
  5. 조건이 거짓이면 반복을 끝냅니다.

📌 i < 5로 바꾸면 1~4까지만 출력합니다. 시작값과 조건에 따라 반복 횟수가 달라집니다.

💡 참고: for 안에서 선언한 i는 해당 반복문 안에서만 사용할 수 있습니다. 이렇게 변수를 사용할 수 있는 범위를 변수의 유효 범위라고 합니다.

2. 반복하면서 합계 구하기

누적은 기존 값에 새로운 값을 계속 더하는 것입니다. 합계를 저장할 변수는 반복문 밖에서 0으로 시작합니다.

파일 이름은 SumFor.java로 저장합니다.

public class SumFor {
    public static void main(String[] args) {
        int total = 0;

        for (int i = 1; i <= 5; i++) {
            total += i;
        }

        System.out.printf("합계: %d%n", total);
    }
}

total += i는 여기서 total = total + i를 짧게 쓴 것입니다.

현재 i 계산 계산 후 total
1 0 + 1 1
2 1 + 2 3
3 3 + 3 6
4 6 + 4 10
5 10 + 5 15

예상 실행 결과:

합계: 15

⚠️ 주의: total을 반복문 안에서 매번 0으로 초기화하면 이전 합계를 이어 갈 수 없습니다. 최종 결과를 한 번만 출력하려면 출력문도 반복문 밖에 둡니다.

3. while: 조건이 참인 동안 반복하기

while은 반복을 시작하기 전에 조건을 검사합니다. 반복할 횟수보다 종료 조건이 중요한 경우에 사용할 수 있습니다.

파일 이름은 CountWhile.java로 저장합니다.

public class CountWhile {
    public static void main(String[] args) {
        int i = 1;

        while (i <= 5) {
            System.out.printf("%d%n", i);
            i++;
        }
    }
}

예상 실행 결과는 앞의 CountFor와 같이 1부터 5까지 한 줄씩 출력됩니다.

⚠️ 주의: 이 예제에서 i++를 빼면 i가 계속 1이므로 반복이 끝나지 않습니다. 종료되지 않고 계속 실행되는 반복을 무한 반복이라고 합니다.

4. do ~ while: 한 번 실행한 뒤 검사하기

do ~ while은 중괄호 안의 코드를 먼저 실행하고 조건을 검사합니다. 따라서 최소 한 번은 실행합니다.

다음 예제는 올바른 메뉴 번호를 입력할 때까지 다시 입력받습니다. 파일 이름은 MenuRetry.java로 저장합니다.

import java.util.Scanner;

public class MenuRetry {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int menu;

        do {
            System.out.print("메뉴 번호를 입력하세요 (1~3): ");
            menu = scanner.nextInt();
        } while (menu < 1 || menu > 3);

        System.out.printf("선택한 메뉴: %d%n", menu);
        scanner.close();
    }
}

예상 실행 화면:

메뉴 번호를 입력하세요 (1~3): 5
메뉴 번호를 입력하세요 (1~3): 2
선택한 메뉴: 2

int menu;는 변수를 만들고 값은 나중에 저장하는 선언입니다. do 안에서 먼저 입력받기 때문에 조건을 검사할 때는 값이 저장되어 있습니다.

📌 do ~ while의 마지막 while (조건); 뒤에는 세미콜론이 필요합니다. 일반 while (조건) { ... }과 구분합니다.

5. break: 반복 끝내기

앞 장에서는 break로 switch를 끝냈습니다. 반복문 안에서는 가장 가까운 반복문을 끝냅니다.

다음 예제는 정수를 계속 입력받아 더하고, 0이 입력되면 끝냅니다. 파일 이름은 SumUntilZero.java로 저장합니다.

import java.util.Scanner;

public class SumUntilZero {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int total = 0;

        while (true) {
            System.out.print("정수를 입력하세요 (0: 종료): ");
            int number = scanner.nextInt();

            if (number == 0) {
                break;
            }
            total += number;
        }

        System.out.printf("합계: %d%n", total);
        scanner.close();
    }
}

예상 실행 화면:

정수를 입력하세요 (0: 종료): 3
정수를 입력하세요 (0: 종료): 4
정수를 입력하세요 (0: 종료): 0
합계: 7

while (true)의 조건은 항상 참입니다. 이 예제에서는 break가 종료 역할을 하므로 0을 입력해야 정상적으로 반복을 마칩니다. 입력값과 합계는 int 범위라고 가정합니다.

6. continue: 이번 반복의 나머지 건너뛰기

continue는 반복 전체를 끝내지 않습니다. 이번 반복에서 남은 코드를 건너뛰고 다음 반복으로 진행합니다.

파일 이름은 EvenNumbers.java로 저장합니다.

public class EvenNumbers {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            if (i % 2 != 0) {
                continue;
            }
            System.out.printf("%d%n", i);
        }
    }
}

예상 실행 결과:

2
4

2로 나눈 나머지가 0이 아니면 홀수입니다. 홀수일 때는 출력문을 건너뛰므로 짝수만 출력됩니다. for에서 continue를 만나도 i++를 실행한 뒤 조건을 다시 검사합니다.

⚠️ 주의: while에서 값 증가 코드를 continue 뒤에 두면 그 코드가 건너뛰어져 무한 반복이 생길 수 있습니다.

7. 반복문 비교

구분 조건 검사 시점 사용 예
for 실행 전 1부터 10까지 출력
while 실행 전 종료값이 입력될 때까지 처리
do ~ while 실행 후 메뉴를 최소 한 번 입력받고 재입력

for와 while은 처음부터 조건이 거짓이면 한 번도 실행하지 않습니다. do ~ while은 처음 한 번 실행한 뒤 계속할지 결정합니다.

학습목표

7-1에서는 반복문의 기본 문법과 break, continue를 배웠습니다. 이번에는 잘못된 입력을 다시 받고, 여러 점수를 모아 통계를 구합니다.

  • 올바른 입력이 들어올 때까지 반복합니다.
  • 종료값과 계산할 값을 구분합니다.
  • 합계·개수·평균을 구하고 중첩 반복문을 추적합니다.

9. 입력 범위가 맞을 때까지 반복하기

6-1에서는 점수가 범위를 벗어나면 안내했습니다. 이제는 안내 후 다시 입력받습니다. 입력은 정수라고 가정합니다.

파일 이름은 ValidScoreInput.java로 저장합니다.

import java.util.Scanner;

public class ValidScoreInput {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int score;

        while (true) {
            System.out.print("점수 입력 (0~100): ");
            score = scanner.nextInt();
            if (score >= 0 && score <= 100) {
                break;
            }
            System.out.printf("0~100 사이의 점수를 입력하세요.%n");
        }

        System.out.printf("저장한 점수: %d%n", score);
        scanner.close();
    }
}

예상 실행 화면:

점수 입력 (0~100): 101
0~100 사이의 점수를 입력하세요.
점수 입력 (0~100): 80
저장한 점수: 80
검사 조건 처리
정상 범위 score >= 0 && score <= 100 반복을 끝내고 저장
범위 밖 score < 0 || score > 100 안내 후 재입력

📌 break는 가장 가까운 반복문을 끝냅니다. 프로그램 전체를 끝내는 명령이 아닙니다.

10. 종료값과 점수를 구분하기

종료값(sentinel value)은 반복을 끝내기 위해 미리 정한 입력입니다. 점수 0도 유효하므로 여기서는 -1을 종료값으로 사용합니다.

if (score == -1)에서 score == -1은 종료 조건(stop condition)입니다. 사용자가 종료값 -1을 입력했는지 검사하고, 참이면 break로 반복을 끝냅니다.

중요한 이유 설명
반복을 끝낼 기준 while (true)는 조건이 항상 참이므로, 사용자가 입력을 마칠 방법이 필요합니다.
입력 의도 구분 0~100은 계산할 점수이고, -1은 입력을 마치겠다는 신호입니다.
계산 오류 방지 종료값을 합계와 개수에 넣지 않도록 누적 계산 전에 검사합니다.

처리 순서를 먼저 정합니다.

  1. 정수를 입력받습니다.
  2. -1이면 반복을 끝냅니다.
  3. 0~100 범위 밖이면 안내하고 다음 입력으로 넘어갑니다.
  4. 유효한 점수만 합계와 개수에 반영합니다.

⚠️ 종료값 검사는 범위 검사보다 먼저 합니다. 범위 검사에서 continue를 먼저 실행하면 -1도 잘못된 점수로 처리되어 종료 조건에 도달하지 못합니다.

📌 break는 가장 가까운 반복문을 끝냅니다. 아래 예제에서는 반복문 뒤의 합계·평균 출력 코드로 이어지며, 점수가 하나도 없으면 계산 대신 안내합니다.

11. 합계·개수·평균 구하기

파일 이름은 ScoreStatistics.java로 저장합니다. 입력 개수와 합계는 int 범위 안이라고 가정합니다.

import java.util.Scanner;

public class ScoreStatistics {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int total = 0;
        int count = 0;

        while (true) {
            System.out.print("점수 입력 (0~100, -1: 종료): ");
            int score = scanner.nextInt();

            if (score == -1) {
                break;
            }
            if (score < 0 || score > 100) {
                System.out.printf("범위를 확인하세요.%n");
                continue;
            }
            total += score;
            count++;
        }

        if (count == 0) {
            System.out.printf("입력한 점수가 없습니다.%n");
        } else {
            double average = (double) total / count;
            System.out.printf("개수: %d%n", count);
            System.out.printf("합계: %d%n", total);
            System.out.printf("평균: %.1f%n", average);
        }
        scanner.close();
    }
}

예상 실행 화면:

점수 입력 (0~100, -1: 종료): 80
점수 입력 (0~100, -1: 종료): 101
범위를 확인하세요.
점수 입력 (0~100, -1: 종료): 0
점수 입력 (0~100, -1: 종료): -1
개수: 2
합계: 80
평균: 40.0
표현 역할
total += score 유효한 점수를 누적
count++ 유효한 점수의 개수만 증가
(double) total / count 실수 나눗셈으로 평균 계산
%.1f 소수점 아래 한 자리 출력

⚠️ double average = total / count;는 정수끼리 나눈 뒤 저장합니다. 85 / 2는 42이므로 결과는 42.0입니다. 나누기 전에 한쪽을 실수로 바꿉니다.

12. 중첩 반복문으로 구구단 확장하기

중첩 반복문은 반복문 안에 다른 반복문을 넣는 것입니다. 바깥 반복문이 한 번 실행될 때 안쪽 반복문은 처음부터 끝까지 실행합니다.

파일 이름은 NestedTable.java로 저장합니다. 출력 흐름을 확인하기 위해 2~3단의 1~3까지만 출력합니다.

public class NestedTable {
    public static void main(String[] args) {
        for (int dan = 2; dan <= 3; dan++) {
            for (int i = 1; i <= 3; i++) {
                System.out.printf("%d x %d = %d%n", dan, i, dan * i);
            }
        }
    }
}

예상 실행 결과:

2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
바깥 반복의 dan 안쪽 반복의 i 출력 줄 수
2 1 → 2 → 3 3
3 다시 1 → 2 → 3 3

dan의 끝값과 i의 끝값을 모두 9로 바꾸면 2~9단을 출력합니다. 중첩 반복문 안의 break는 가장 가까운 안쪽 반복문만 끝낸다는 점도 확인합니다.

13. 반복문 오류 점검

증상 확인할 부분
합계가 마지막 점수와 같음 누적 변수를 반복 안에서 초기화했는가?
잘못된 점수도 개수에 포함 count++가 범위 검사 뒤에 있는가?
처음부터 종료하면 계산 오류 count == 0을 먼저 검사했는가?

14. 연습: 합격자 수까지 구하기

ScoreStatistics.java를 복사해 ScoreSummary.java로 만듭니다. 클래스 이름도 ScoreSummary로 변경합니다.

  • 60점 이상인 유효 점수의 개수를 추가로 셉니다.
  • 종료값과 범위 밖 입력은 합격자 수에도 넣지 않습니다.
  • 59, 60, 100, -1 입력 시 개수 3, 합계 219, 평균 73.0, 합격자 수 2가 나와야 합니다.

✅ 확인할 것:

  • 첫 입력 -1에서는 입력한 점수가 없습니다.를 출력합니다.
  • 0, 100은 정상 점수입니다. -2, 101은 다시 입력받습니다.
