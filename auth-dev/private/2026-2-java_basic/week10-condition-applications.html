1. 독립된 if와 연결된 조건문

독립된 if는 조건을 각각 검사합니다. if ~ else if는 위에서부터 검사하고 처음 참인 경우 하나만 실행합니다.

파일 이름은 ConditionFlow.java로 저장합니다.

public class ConditionFlow {
    public static void main(String[] args) {
        int score = 95;

        System.out.printf("독립된 if:%n");
        if (score >= 90) {
            System.out.printf("90점 이상%n");
        }
        if (score >= 80) {
            System.out.printf("80점 이상%n");
        }

        System.out.printf("연결된 조건문:%n");
        if (score >= 90) {
            System.out.printf("A등급%n");
        } else if (score >= 80) {
            System.out.printf("B등급%n");
        }
    }
}

예상 실행 결과:

독립된 if:
90점 이상
80점 이상
연결된 조건문:
A등급

📌 여러 안내를 각각 출력하려면 독립된 if를 사용합니다. 등급처럼 하나만 선택하려면 연결된 조건문을 사용합니다.

2. 입력 범위를 먼저 확인하기

점수가 0~100 범위를 벗어나면 등급을 매기지 않아야 합니다. 잘못된 범위를 먼저 검사하면 뒤의 조건을 이해하기 쉽습니다.

파일 이름은 GradeCheck.java로 저장합니다.

import java.util.Scanner;

public class GradeCheck {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("점수를 입력하세요: ");
        int score = scanner.nextInt();

        if (score < 0 || score > 100) {
            System.out.printf("점수는 0~100 사이여야 합니다.%n");
        } else if (score >= 90) {
            System.out.printf("A등급%n");
        } else if (score >= 80) {
            System.out.printf("B등급%n");
        } else if (score >= 70) {
            System.out.printf("C등급%n");
        } else {
            System.out.printf("재학습이 필요합니다.%n");
        }

        scanner.close();
    }
}

예상 실행 화면:

점수를 입력하세요: 85
B등급
입력 예상 판정
-1, 101 범위 안내
0, 69 재학습 필요
70, 79 C등급
80, 89 B등급
90, 100 A등급

💡 참고: 조건이 달라지는 지점의 값을 경계값이라고 합니다. 89와 90처럼 경계 바로 앞뒤의 값을 넣어 보면 조건 오류를 찾기 쉽습니다.

3. 중첩 조건문과 문자열 비교

중첩 조건문은 조건문 안에 다른 조건문을 넣는 것입니다. 먼저 한 조건을 확인하고, 그 경우에만 추가로 판단할 때 사용합니다.

다음 예제는 구매 금액이 10,000원 이상인 경우에 회원 여부를 확인합니다. 회원은 1,000원을 할인받습니다.

새 표현 의미
scanner.next() 공백으로 구분된 문자열 하나를 읽습니다.
member.equals("Y") 입력한 문자열의 내용이 "Y"와 같은지 비교합니다.

⚠️ 주의: 문자열의 내용을 비교할 때는 == 대신 equals()를 사용합니다. 여기서는 대문자 Y 또는 N을 입력한다고 가정합니다.

파일 이름은 MemberDiscount.java로 저장합니다.

import java.util.Scanner;

public class MemberDiscount {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("구매 금액을 입력하세요: ");
        int price = scanner.nextInt();
        System.out.print("회원인가요? (Y/N): ");
        String member = scanner.next();

        int discount = 0;
        if (price >= 10000) {
            if (member.equals("Y")) {
                discount = 1000;
            }
        }

        int payment = price - discount;
        System.out.printf("할인 금액: %d원%n", discount);
        System.out.printf("결제 금액: %d원%n", payment);

        scanner.close();
    }
}

예상 실행 화면:

구매 금액을 입력하세요: 15000
회원인가요? (Y/N): Y
할인 금액: 1000원
결제 금액: 14000원

구매 금액은 0 이상의 정수라고 가정합니다. 두 조건 중 하나라도 만족하지 않으면 discount는 처음 값인 0을 유지합니다.

이 예제의 중첩 조건문은 다음처럼 한 조건문으로 표현할 수도 있습니다.

if (price >= 10000 && member.equals("Y")) {
    discount = 1000;
}

📌 두 조건을 모두 만족할 때 같은 작업 하나를 한다면 &&로 연결할 수 있습니다. 조건별로 다른 안내나 동작이 필요하면 중첩 조건문을 사용할 수 있습니다.

4. switch: 메뉴 번호로 선택하기

switch는 하나의 값을 정해진 여러 값과 비교할 때 사용합니다. 여기서는 정수 메뉴 번호를 비교합니다.

표현 역할
switch (menu) 비교할 값을 지정합니다.
case 1: 값이 1일 때 실행을 시작합니다.
break; 현재 switch를 빠져나갑니다.
default: 일치하는 case가 없을 때 실행합니다.

파일 이름은 DrinkMenu.java로 저장합니다.

import java.util.Scanner;

public class DrinkMenu {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.printf("1. 물  2. 주스  3. 차%n");
        System.out.print("메뉴 번호를 입력하세요: ");
        int menu = scanner.nextInt();

        switch (menu) {
            case 1:
                System.out.printf("물을 선택했습니다.%n");
                break;
            case 2:
                System.out.printf("주스를 선택했습니다.%n");
                break;
            case 3:
                System.out.printf("차를 선택했습니다.%n");
                break;
            default:
                System.out.printf("없는 메뉴입니다.%n");
                break;
        }

        scanner.close();
    }
}

예상 실행 화면:

1. 물  2. 주스  3. 차
메뉴 번호를 입력하세요: 2
주스를 선택했습니다.

⚠️ 주의: 위처럼 콜론(:)을 쓰는 switch에서 break를 빠뜨리면 뒤쪽 case의 코드까지 이어서 실행할 수 있습니다.

판단할 내용 사용할 문법
점수 범위나 여러 조건의 조합 if ~ else if
정해진 메뉴 번호와 일치하는지 확인 switch

5. 연습: 입장료 계산

  • 파일 이름은 AdmissionFee.java로 저장합니다.
  • Scanner로 나이 하나를 정수로 입력받습니다.
  • 나이가 0~120 범위를 벗어나면 나이를 확인하세요.만 출력합니다.
  • 정상 범위에서는 아래 기준으로 입장료를 출력합니다.
나이 입장료
0~7세 무료
8~18세 5,000원
19~64세 10,000원
65~120세 무료

예상 실행 화면:

나이를 입력하세요: 18
입장료: 5000원

무료인 경우에도 입장료: 0원으로 출력합니다. 잘못된 범위를 먼저 검사하고, 이후 나이가 작은 구간부터 판단해 봅니다.

✅ 확인할 것:

  • -1, 121에서는 입장료를 출력하지 않습니다.
  • 7, 8, 18, 19, 64, 65를 넣어 구간이 정확히 나뉘는지 확인합니다.
  • 하나의 입력에 결과가 중복 출력되지 않습니다.
