학습목표

조건문부터 클래스까지 배운 내용을 하나의 프로그램으로 연결합니다. 이번에는 새 문법을 많이 늘리기보다 기능을 나누고 경계 상황을 확인합니다.

  • 메뉴를 반복하며 학생을 등록·조회·수정합니다.
  • 객체 배열의 저장 공간과 실제 인원을 구분합니다.
  • 메서드와 객체의 역할을 나누고 잘못된 입력을 처리합니다.

1. 요구사항 정하기

메뉴 기능 확인할 조건
1 학생 등록 최대 5명, 중복 이름 금지, 점수 0~100
2 전체 목록 등록된 학생만 출력
3 통계 합계·평균·최고점, 빈 목록은 안내
4 이름 검색 문자열 내용을 equals()로 비교
5 점수 수정 없는 학생·범위 밖 점수는 안내
0 종료 메뉴 반복 종료

이름은 공백이 없는 한 단어를 사용합니다. 프로그램을 종료하면 데이터는 사라집니다. 파일·DB 저장 기능은 포함하지 않습니다.

2. 데이터와 동작 나누기

대상 담당하는 일
Student 이름·점수 보관, 등급 계산, 점수 변경 검증
Student[] students 학생 객체를 담는 공간 5개
count 실제 등록 인원
GradeManager의 메서드 입력, 메뉴, 검색, 목록, 통계

10-1의 학생 객체와 같은 방식입니다. 복사해서 바로 실행할 수 있도록 아래 예제는 Student 정의도 포함합니다. 이전 StudentDemo.java 등과 같은 폴더에서 한꺼번에 컴파일하지 않습니다.

2.1 문자 입력을 다시 받기

앞의 예제는 정수를 입력한다고 가정했습니다. 여기서는 Scanner.hasNextInt()로 다음 입력을 정수로 읽을 수 있는지 먼저 검사합니다.

표현 역할
scanner.hasNextInt() 다음 입력이 int로 읽힐 수 있는지 검사. 입력을 소비하지 않음
scanner.next() 잘못된 입력 한 단어를 읽어 버림
scanner.nextInt() 정수를 실제로 읽음

⚠️ 잘못된 입력을 읽어 버리지 않으면 같은 입력을 계속 검사해 반복이 끝나지 않습니다. 이 예제는 사용자가 입력을 계속 제공한다고 가정합니다. 파일 입력의 끝이나 터미널 입력 종료 처리는 별도 주제입니다.

3. 완성 예제

파일 이름은 GradeManager.java로 저장합니다.

import java.util.Scanner;

class Student {
    private String name;
    private int score;

    Student(String name, int score) {
        if (score < 0 || score > 100) {
            throw new IllegalArgumentException("점수는 0~100입니다.");
        }
        this.name = name;
        this.score = score;
    }

    String getName() {
        return name;
    }

    int getScore() {
        return score;
    }

    boolean changeScore(int score) {
        if (score < 0 || score > 100) {
            return false;
        }
        this.score = score;
        return true;
    }

    String grade() {
        if (score >= 90) {
            return "A";
        } else if (score >= 80) {
            return "B";
        } else if (score >= 70) {
            return "C";
        } else {
            return "재학습";
        }
    }
}

public class GradeManager {
    static int readInt(Scanner scanner, String prompt) {
        System.out.print(prompt);
        while (!scanner.hasNextInt()) {
            scanner.next();
            System.out.printf("정수로 입력하세요.%n");
            System.out.print(prompt);
        }
        return scanner.nextInt();
    }

    static int findByName(Student[] students, int count, String name) {
        for (int i = 0; i < count; i++) {
            if (students[i].getName().equals(name)) {
                return i;
            }
        }
        return -1;
    }

    static int register(Scanner scanner, Student[] students, int count) {
        if (count == students.length) {
            System.out.printf("저장 공간이 가득 찼습니다.%n");
            return count;
        }
        System.out.print("이름 (공백 없이): ");
        String name = scanner.next();
        if (findByName(students, count, name) != -1) {
            System.out.printf("이미 등록된 이름입니다.%n");
            return count;
        }
        int score = readInt(scanner, "점수 (0~100): ");
        if (score < 0 || score > 100) {
            System.out.printf("점수 범위를 확인하세요. 등록하지 않았습니다.%n");
            return count;
        }
        students[count] = new Student(name, score);
        System.out.printf("등록했습니다.%n");
        return count + 1;
    }

    static void printStudent(Student student) {
        System.out.printf("%s: %d점, %s%n",
                student.getName(), student.getScore(), student.grade());
    }

    static void printList(Student[] students, int count) {
        if (count == 0) {
            System.out.printf("등록된 학생이 없습니다.%n");
            return;
        }
        for (int i = 0; i < count; i++) {
            printStudent(students[i]);
        }
    }

    static void printStatistics(Student[] students, int count) {
        if (count == 0) {
            System.out.printf("등록된 학생이 없습니다.%n");
            return;
        }
        int total = 0;
        int max = students[0].getScore();
        for (int i = 0; i < count; i++) {
            int score = students[i].getScore();
            total += score;
            if (score > max) {
                max = score;
            }
        }
        System.out.printf("인원: %d명%n합계: %d%n", count, total);
        System.out.printf("평균: %.2f%n최고점: %d%n", (double) total / count, max);
    }

    static void search(Scanner scanner, Student[] students, int count) {
        System.out.print("찾을 이름: ");
        int index = findByName(students, count, scanner.next());
        if (index == -1) {
            System.out.printf("학생을 찾지 못했습니다.%n");
        } else {
            printStudent(students[index]);
        }
    }

    static void update(Scanner scanner, Student[] students, int count) {
        System.out.print("수정할 이름: ");
        int index = findByName(students, count, scanner.next());
        if (index == -1) {
            System.out.printf("학생을 찾지 못했습니다.%n");
            return;
        }
        int score = readInt(scanner, "새 점수 (0~100): ");
        if (students[index].changeScore(score)) {
            System.out.printf("수정했습니다.%n");
        } else {
            System.out.printf("범위 밖 점수입니다. 기존 점수를 유지합니다.%n");
        }
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        Student[] students = new Student[5];
        int count = 0;

        while (true) {
            System.out.printf("1. 등록  2. 목록  3. 통계  4. 검색  5. 수정  0. 종료%n");
            int menu = readInt(scanner, "메뉴: ");
            if (menu == 0) {
                break;
            }
            switch (menu) {
                case 1:
                    count = register(scanner, students, count);
                    break;
                case 2:
                    printList(students, count);
                    break;
                case 3:
                    printStatistics(students, count);
                    break;
                case 4:
                    search(scanner, students, count);
                    break;
                case 5:
                    update(scanner, students, count);
                    break;
                default:
                    System.out.printf("없는 메뉴입니다.%n");
                    break;
            }
        }
        System.out.printf("종료합니다.%n");
        scanner.close();
    }
}

4. 실행 흐름 따라가기

다음은 메뉴 1, 이름 가람, 점수 85, 메뉴 2, 메뉴 0 순서로 입력한 화면입니다.

1. 등록  2. 목록  3. 통계  4. 검색  5. 수정  0. 종료
메뉴: 1
이름 (공백 없이): 가람
점수 (0~100): 85
등록했습니다.
1. 등록  2. 목록  3. 통계  4. 검색  5. 수정  0. 종료
메뉴: 2
가람: 85점, B
1. 등록  2. 목록  3. 통계  4. 검색  5. 수정  0. 종료
메뉴: 0
종료합니다.
순서 데이터 변화
처음 배열 길이 5, count = 0
등록 성공 students[0]에 객체 저장, 반환받은 count = 1
목록 i < count인 원소만 읽음
종료 바깥 while을 끝내고 Scanner를 닫음

📌 register는 count의 복사본을 받습니다. 호출 후 count = register(...)로 반환값을 다시 저장해야 등록 인원이 유지됩니다. 배열 원소의 변경은 같은 배열에 반영됩니다.

5. 앞에서 배운 주의점 연결하기

  • default가 있어 등록되지 않은 메뉴도 안내합니다.
  • 메뉴의 break는 switch만 끝냅니다. 종료 메뉴는 switch 앞에서 반복문을 끝냅니다.
  • 이름은 == 대신 equals()로 비교합니다.
  • 빈 목록에서 평균과 첫 원소를 사용하지 않습니다.
  • 사용하지 않는 배열 원소는 null이므로 count까지만 읽습니다.
  • 점수 범위를 검사하고, 평균은 실수로 나눕니다.
  • 패턴 매칭·레코드·스트림 없이 앞에서 배운 기본 문법을 연결합니다.

6. 기능별 확인과 확장 실습

입력 상황 예상 결과
등록 전 메뉴 2·3 등록된 학생이 없다는 안내
메뉴 9 없는 메뉴 안내 후 재입력
메뉴에 abc 정수 안내 후 재입력
점수 -1, 101 등록하지 않고 인원도 유지
점수 0, 100 등록 성공
같은 이름 재등록 중복 이름 안내, 추가 등록 안 함
여섯 번째 등록 저장 공간 안내, 범위 오류 없이 계속
없는 이름 검색·수정 찾지 못했다는 안내
수정 점수 101 기존 점수 유지

확장 실습은 다음 순서로 진행합니다.

  1. 통계에 60점 이상인 학생 수를 추가합니다.
  2. 최고점 학생의 이름을 함께 출력합니다. 동점이면 모두 출력합니다.
  3. 이름 검색 결과를 입력과 출력으로 나눈 이유를 설명합니다.

✅ 완료 기준:

  • 0점과 미등록 공간을 구분합니다.
  • 문자 입력·잘못된 메뉴·저장 공간 초과를 안내합니다.
  • 등록 후 조회와 수정 후 재조회가 일치합니다.
  • Student의 검증과 메뉴 프로그램의 입력 검증 역할을 설명합니다.
