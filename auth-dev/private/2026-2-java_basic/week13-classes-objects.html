1. 클래스는 정의, 객체는 실제 데이터

클래스는 어떤 데이터와 동작을 가질지 정의합니다. 객체는 그 정의에 따라 만들어진 실제 데이터입니다. 클래스로 만든 객체를 인스턴스라고도 합니다.

용어 역할 학생 예
클래스 자료형과 동작 정의 Student
필드 객체가 보관하는 값 이름, 점수
생성자 객체를 만들 때 초기 상태 설정 Student("가람", 85)
메서드 객체가 할 수 있는 동작 등급 구하기, 점수 변경
객체 생성 실제 객체 만들기 new Student("가람", 85)

6-1의 패턴 매칭에서는 String과 Integer 같은 기존 자료형을 검사했습니다. 이제는 직접 Student라는 자료형을 만듭니다. 이 장은 Java 21의 패턴 매칭 기능을 사용하지 않습니다.

2. 학생 한 명을 만드는 완성 예제

파일 이름은 StudentDemo.java로 저장합니다. 한 파일에 두 클래스를 쓰지만 public 클래스는 StudentDemo 하나입니다. 실행을 시작하는 main도 이 클래스에 둡니다.

class Student {
    private String name;
    private int score;

    Student(String name, int score) {
        if (score < 0 || score > 100) {
            throw new IllegalArgumentException("점수는 0~100입니다.");
        }
        this.name = name;
        this.score = score;
    }

    String getName() {
        return name;
    }

    int getScore() {
        return score;
    }

    boolean changeScore(int score) {
        if (score < 0 || score > 100) {
            return false;
        }
        this.score = score;
        return true;
    }

    String grade() {
        if (score >= 90) {
            return "A";
        } else if (score >= 80) {
            return "B";
        } else if (score >= 70) {
            return "C";
        } else {
            return "재학습";
        }
    }
}

public class StudentDemo {
    public static void main(String[] args) {
        Student student = new Student("가람", 85);
        System.out.printf("%s: %d점, %s%n",
                student.getName(), student.getScore(), student.grade());

        boolean changed = student.changeScore(95);
        System.out.printf("변경 성공: %b%n", changed);
        System.out.printf("새 등급: %s%n", student.grade());

        changed = student.changeScore(101);
        System.out.printf("변경 성공: %b%n", changed);
        System.out.printf("현재 점수: %d%n", student.getScore());
    }
}

예상 실행 결과:

가람: 85점, B
변경 성공: true
새 등급: A
변경 성공: false
현재 점수: 95

이름은 비어 있지 않은 문자열이라고 가정합니다. 입력받는 프로그램에서는 객체를 만들기 전에 점수 범위를 검사합니다.

2.1 생성자와 this

생성자는 클래스 이름과 같고 반환형을 쓰지 않습니다. void Student(...)로 작성하면 생성자가 아닌 일반 메서드가 됩니다.

표현 뜻
생성자의 name, score 전달받은 매개변수
this.name, this.score 지금 만드는 객체의 필드
this.score = score 매개변수의 값을 객체에 보관

💡 참고: IllegalArgumentException은 잘못된 인수를 전달했음을 알리는 예외입니다. throw new ...가 실행되면 생성을 정상적으로 마치지 못합니다. 이 장에서는 범위 검사의 마지막 방어로 사용하며, 예외를 잡아 복구하는 방법은 후속 내용으로 둡니다.

2.2 private와 점수 변경 메서드

private 필드는 다른 클래스에서 직접 접근할 수 없습니다. student.score = 101;처럼 바꾸지 않고 changeScore(101)을 호출합니다. 잘못된 값은 false를 반환하고 기존 점수는 유지합니다. 이처럼 내부 데이터를 숨기고 정해진 메서드로 다루는 것을 캡슐화라고 합니다.

📌 생성자 검사와 변경 메서드 검사는 서로 다른 순간의 검증입니다. 처음 만드는 순간과 나중에 수정하는 순간 모두 유효한 상태를 유지합니다.

3. static 메서드와 객체 메서드

비교 9-1의 static 메서드 Student의 객체 메서드
예 grade(score) student.grade()
필요한 데이터 매개변수로 받음 해당 객체의 필드를 사용
객체 생성 필요 없음 호출할 객체 필요

main은 static이므로 Student의 score를 바로 읽을 수 없습니다. 먼저 객체를 만들고 그 객체의 메서드를 호출합니다. getName(), getScore()처럼 필드 값을 읽는 메서드를 흔히 getter라고 부릅니다.

4. 객체 배열로 학생 여러 명 다루기

앞의 StudentDemo.java를 복사해 StudentArrayDemo.java로 만듭니다. Student 정의는 그대로 두고, public class StudentDemo부터 끝까지 아래 코드로 바꿉니다. 예제는 각각 별도 폴더에서 실행해 같은 이름의 Student가 중복 컴파일되지 않게 합니다.

public class StudentArrayDemo {
    public static void main(String[] args) {
        Student[] students = new Student[3];
        students[0] = new Student("가람", 90);
        students[1] = new Student("나래", 60);
        int count = 2;
        int total = 0;

        for (int i = 0; i < count; i++) {
            Student student = students[i];
            total += student.getScore();
            System.out.printf("%s: %s%n", student.getName(), student.grade());
        }
        System.out.printf("평균: %.1f%n", (double) total / count);
    }
}

예상 실행 결과:

가람: A
나래: 재학습
평균: 75.0

⚠️ new Student[3]은 학생 객체 세 개를 만드는 것이 아닙니다. 객체를 가리킬 공간 세 개를 만들고, 각 원소는 처음에 null입니다. 위의 마지막 원소는 비어 있으므로 i < count로 반복합니다. null에 메서드를 호출하면 NullPointerException이 발생합니다.

5. 내용 비교와 같은 객체 비교

비교 목적 표현 주의점
학생 이름의 내용 비교 student.getName().equals("가람") 문자열에 ==를 쓰지 않음
같은 학생 객체를 가리키는지 first == second 내용 전체 비교가 아님
점수 값 비교 first.getScore() == second.getScore() 기본형 int의 값 비교

직접 만든 Student의 equals()가 필드 내용을 자동으로 비교해 주는 것은 아닙니다. String.equals()의 동작을 모든 객체에 그대로 일반화하지 않습니다.

6. 연습: 같은 학생을 가리키는 변수

StudentDemo의 main에 다음 코드를 추가해 봅니다.

Student first = new Student("가람", 85);
Student second = first;
second.changeScore(90);
System.out.println(first == second);  // true
System.out.println(first.getScore()); // 90

두 변수는 같은 객체를 가리킵니다. 독립된 학생을 만들려면 new Student(...)를 다시 호출해야 합니다.

✅ 확인할 것:

  • 객체 두 개의 점수는 각각 따로 보관됩니다.
  • changeScore(-1)과 changeScore(101)은 실패하고 기존 값은 유지됩니다.
  • changeScore(0)과 changeScore(100)은 성공합니다.
  • 생성자 이름, 파일 이름, public 클래스 이름을 확인합니다.
