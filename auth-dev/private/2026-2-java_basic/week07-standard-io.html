1. 표준 입력과 표준 출력

표준 입력은 프로그램이 값을 읽는 기본 통로입니다. 표준 출력은 프로그램이 결과를 내보내는 기본 통로입니다. 이번 실습에서는 키보드로 입력하고 콘솔 화면으로 출력합니다. 콘솔은 프로그램의 문자 입력과 출력을 확인하는 창입니다.

구분 Java 표현 이번 실습에서의 역할
표준 입력 System.in 키보드로 입력한 값을 읽습니다.
표준 출력 System.out 안내 문구와 계산 결과를 출력합니다.

입력값은 입력 → 계산 → 출력 순서로 처리합니다.

2. 출력 방법 비교

방법 특징 사용 예
print() 출력 후 줄을 바꾸지 않습니다. System.out.print("정수 입력: ");
println() 출력 후 줄을 바꿉니다. System.out.println("입력 완료");
printf() 지정한 형식에 맞춰 출력합니다. 줄바꿈은 %n으로 지정합니다. System.out.printf("결과: %d%n", result);

print()는 안내 문구 옆에 값을 입력받을 때 사용합니다. println()은 계산 결과를 한 줄로 출력할 때 사용합니다. printf()는 정수나 실수의 출력 형식을 지정할 때 사용합니다.

💡 참고: 앞 교안에서는 printf()를 사용했습니다. 이번에는 제시된 예제를 따라 print()와 println()도 함께 연습합니다. printf()를 사용할 때는 "결과: %d%n"처럼 출력 형식을 코드에 정해 두고, 값은 뒤쪽 인자로 전달합니다.

3. 입력 방법 1: Scanner

Scanner는 입력한 내용을 정수, 실수, 문자열 등으로 읽을 수 있는 도구입니다. nextInt()를 호출하면 다음 정수 하나를 읽습니다.

파일 이름은 CalculatorScannerIO.java로 저장합니다.

import java.util.Scanner;

public class CalculatorScannerIO {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in); // 키보드 입력 준비

        System.out.print("첫 번째 정수를 입력하세요: ");
        int x = scanner.nextInt();                // 첫 번째 정수 저장

        System.out.print("두 번째 정수를 입력하세요: ");
        int y = scanner.nextInt();                // 두 번째 정수 저장

        int result = x + y;
        System.out.println("덧셈 결과: " + result);

        scanner.close();                          // 입력 도구 닫기
    }
}

예상 실행 화면:

첫 번째 정수를 입력하세요: 3
두 번째 정수를 입력하세요: 4
덧셈 결과: 7

3을 입력하고 Enter를 누릅니다. 두 번째 안내가 나오면 4를 입력하고 Enter를 누릅니다. 실행 화면의 3과 4는 사용자가 입력한 값입니다.

3.1 코드 살펴보기

코드 설명
import java.util.Scanner; Java에서 제공하는 Scanner를 사용하도록 준비합니다.
new Scanner(System.in) 표준 입력을 읽는 Scanner 객체를 만듭니다. 객체는 여기서 실제로 사용할 입력 도구라고 생각하면 됩니다.
scanner.nextInt() 다음 정수 하나를 읽어 int 값으로 반환합니다.
int result = x + y; 입력한 두 정수를 더해 저장합니다.
"덧셈 결과: " + result 안내 문자열 뒤에 계산 결과를 이어 붙입니다.
scanner.close(); 입력 도구를 닫습니다.

⚠️ 주의: 이 예제에서는 모든 입력이 끝난 뒤 close()를 호출합니다. 연결된 System.in도 닫히므로 같은 프로그램에서 이후에 키보드 입력을 다시 받으면 안 됩니다.

4. 입력 방법 2: BufferedReader

BufferedReader는 입력 내용을 임시 공간인 버퍼에 모아 읽는 도구입니다. readLine()은 한 줄을 문자열로 읽습니다. 계산에 사용할 정수로 바꾸려면 Integer.parseInt()가 필요합니다.

파일 이름은 CalculatorBufferedReaderIO.java로 저장합니다. 각 예제는 클래스 이름과 같은 이름의 파일에 저장하고 독립적으로 실행합니다.

import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class CalculatorBufferedReaderIO {
    public static void main(String[] args) throws IOException {
        BufferedReader reader =
            new BufferedReader(new InputStreamReader(System.in));

        System.out.print("첫 번째 정수를 입력하세요: ");
        int x = Integer.parseInt(reader.readLine());

        System.out.print("두 번째 정수를 입력하세요: ");
        int y = Integer.parseInt(reader.readLine());

        int result = x + y;
        System.out.println("덧셈 결과: " + result);

        reader.close();
    }
}

예상 실행 화면:

첫 번째 정수를 입력하세요: 3
두 번째 정수를 입력하세요: 4
덧셈 결과: 7

이번에도 정수를 한 줄에 하나씩 입력합니다.

4.1 코드 살펴보기

코드 설명
InputStreamReader(System.in) 표준 입력의 바이트 데이터를 문자로 읽도록 바꿉니다. 바이트는 데이터를 표현하는 단위입니다.
new BufferedReader(...) 문자 입력에 버퍼를 덧붙여 한 줄씩 읽을 수 있게 합니다.
reader.readLine() Enter 전까지 입력한 한 줄을 문자열로 읽습니다. 줄바꿈 문자는 결과에 포함하지 않습니다.
Integer.parseInt(...) "3" 같은 정수 모양의 문자열을 int 값 3으로 바꿉니다.
throws IOException 입력·출력 중 발생할 수 있는 오류를 이 메소드 안에서 처리하지 않고 호출한 쪽으로 전달한다고 선언합니다.
reader.close(); 입력 도구와 연결된 표준 입력을 닫습니다.

💡 참고: 프로그램 실행 중 발생하는 오류 상황을 예외라고 합니다. IOException은 입력·출력 관련 예외입니다. 지금은 위 코드의 선언을 사용하고, 예외를 직접 처리하는 방법은 이후에 배웁니다. throws IOException이 오류를 자동으로 해결해 주는 것은 아닙니다.

📌 readLine()의 결과는 문자열입니다. 숫자 모양이어도 계산하려면 정수로 변환해야 합니다. 이는 앞에서 배운 (int) 형 변환과 구분합니다.

5. 공백으로 구분된 두 정수 입력받기

이번에는 3과 4를 한 줄에 입력합니다. 두 수 사이에 공백을 넣어 3 4를 입력한 뒤 Enter를 누릅니다.

5.1 Scanner로 입력받기

Scanner는 기본적으로 공백, 탭, 줄바꿈을 값 사이의 구분자로 사용합니다. 구분자는 입력값을 나누는 기준입니다. nextInt()를 두 번 호출하면 한 줄에 입력한 두 정수를 차례로 읽습니다.

파일 이름은 CalculatorScannerIO2.java로 저장합니다.

import java.util.Scanner;

public class CalculatorScannerIO2 {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("두 정수를 입력하세요 (예: 3 4): ");
        int x = scanner.nextInt(); // 첫 번째 정수: 3
        int y = scanner.nextInt(); // 두 번째 정수: 4

        int result = x + y;
        System.out.println("덧셈 결과: " + result);

        scanner.close();
    }
}

예상 실행 화면:

두 정수를 입력하세요 (예: 3 4): 3 4
덧셈 결과: 7

3 4처럼 공백을 여러 개 넣어도 됩니다. 3과 4를 서로 다른 줄에 입력해도 두 번의 nextInt()가 차례로 읽습니다. 정수 하나만 입력하면 두 번째 정수를 입력할 때까지 기다립니다.

5.2 BufferedReader로 입력받기

readLine()은 3 4 전체를 문자열 하나로 읽습니다. Integer.parseInt("3 4")로는 정수 하나를 만들 수 없습니다. 먼저 문자열을 두 부분으로 나누고, 각각 정수로 바꿉니다.

아래 예제에서는 다음 표현을 사용합니다.

표현 의미
trim() 문자열 앞뒤의 공백을 제거합니다.
split("\\s+") 하나 이상의 공백이나 탭을 기준으로 문자열을 나눕니다.
String[] values 나눈 문자열 여러 개를 순서대로 담는 배열입니다. 배열은 여러 값을 묶어 저장하는 방법입니다.
values[0], values[1] 배열의 첫 번째 값과 두 번째 값입니다. 배열의 위치 번호는 0부터 시작합니다.

💡 참고: "\\s+"는 문자를 찾는 규칙인 정규 표현식을 Java 문자열로 적은 것입니다. 여기서는 공백이 여러 개여도 나눌 수 있는 표현으로 사용합니다. 배열과 정규 표현식의 자세한 사용법은 이후에 배웁니다.

파일 이름은 CalculatorBufferedReaderIO2.java로 저장합니다.

import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class CalculatorBufferedReaderIO2 {
    public static void main(String[] args) throws IOException {
        BufferedReader reader =
            new BufferedReader(new InputStreamReader(System.in));

        System.out.print("두 정수를 입력하세요 (예: 3 4): ");
        String line = reader.readLine();
        String[] values = line.trim().split("\\s+");

        int x = Integer.parseInt(values[0]);
        int y = Integer.parseInt(values[1]);

        int result = x + y;
        System.out.println("덧셈 결과: " + result);

        reader.close();
    }
}

예상 실행 화면:

두 정수를 입력하세요 (예: 3 4): 3 4
덧셈 결과: 7

입력한 "3 4"는 "3"과 "4"로 나뉩니다. 이를 정수 3과 4로 변환해 더합니다. 이 예제는 readLine()을 한 번만 호출하므로 두 정수를 같은 줄에 입력해야 합니다.

⚠️ 주의: 이번 예제는 안내한 개수의 올바른 정수가 입력된다고 가정합니다. 문자나 소수, int 범위를 벗어난 값을 입력하면 정수로 읽거나 변환할 수 없습니다. 마지막 예제에서 한 줄에 정수를 하나만 입력하면 두 번째 값이 없어 오류가 발생합니다.

6. 두 입력 방법 비교

구분 Scanner BufferedReader
이번 예제의 읽기 단위 nextInt()로 정수 하나씩 readLine()으로 한 줄씩
정수 변환 nextInt()가 처리 Integer.parseInt()를 직접 사용
한 줄의 3 4 입력 nextInt()를 두 번 호출 한 줄을 읽고 나눈 뒤 각각 변환
코드 작성 정수를 간단하게 읽을 수 있음 문자열 분리와 변환 과정이 필요함

📌 두 방법 모두 입력 도구입니다. 계산과 출력 부분은 같고, 값을 읽어 정수로 만드는 과정이 다릅니다.

7. 연습: 물건 구매 금액 계산

물건 한 개의 가격과 구매 개수를 한 줄에 공백으로 구분하여 입력받고, 총금액을 출력합니다.

  • 가격과 개수는 양의 정수이며, 계산 결과는 int 범위 안이라고 가정합니다.
  • 총금액은 가격 * 개수로 계산합니다. *는 곱셈 연산자입니다.
  • 먼저 Scanner로 작성합니다.
  • 같은 파일의 입력 부분을 BufferedReader 방식으로 바꾸어 다시 실행합니다.
  • 결과는 System.out.printf("총금액: %d원%n", total);로 출력합니다.

예상 실행 화면:

가격과 개수를 입력하세요: 1500 3
총금액: 4500원

✅ 확인할 것:

  • 두 입력 방법 모두 1500 3을 입력하면 4500원이 출력됩니다.
  • 2000 4를 입력하면 8000원이 출력됩니다.

  • 입력을 모두 마친 뒤 입력 도구를 닫습니다.
