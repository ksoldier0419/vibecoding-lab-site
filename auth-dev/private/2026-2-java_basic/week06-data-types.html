학습목표

변수에는 값을 저장합니다. 그런데 모든 값이 같은 종류는 아닙니다. 정수, 실수, 문자, 참/거짓, 문자열처럼 값의 종류가 다릅니다.

Java에서는 변수에 값을 저장할 때 자료형을 먼저 정합니다. 자료형은 변수에 어떤 종류의 값을 저장할 수 있는지 알려주는 표시입니다.

1. 시작 예제: DataTypeExample.java

파일 이름은 DataTypeExample.java로 저장합니다.

public class DataTypeExample {
    public static void main(String[] args) {
        int age = 20;
        double height = 175.5;
        char grade = 'A';
        boolean isStudent = true;
        String name = "Kim";

        System.out.printf("name: %s%n", name);
        System.out.printf("age: %d%n", age);
        System.out.printf("height: %.1f%n", height);
        System.out.printf("grade: %c%n", grade);
        System.out.printf("student: %b%n", isStudent);
    }
}

실행 결과:

name: Kim
age: 20
height: 175.5
grade: A
student: true

2. 코드 살펴보기

코드 설명
int age = 20; 정수 값을 저장합니다.
double height = 175.5; 소수점이 있는 실수 값을 저장합니다.
char grade = 'A'; 문자 하나를 저장합니다. 작은따옴표를 사용합니다.
boolean isStudent = true; 참 또는 거짓 값을 저장합니다.
String name = "Kim"; 문자열을 저장합니다. 큰따옴표를 사용합니다.

💡 참고: char는 문자 하나, String은 여러 글자로 이루어진 문자열을 저장할 때 사용합니다.

3. 기본 자료형 (수정: 2026.10.15)

기본 자료형(primitive type)은 정수, 실수, 문자, 참/거짓 같은 기본 값을 나타내는 자료형입니다. 기본 자료형의 변수에는 값 자체를 저장합니다. Java의 기본 자료형은 8개입니다. 1바이트는 8비트입니다. 아래 크기는 자료형이 표현하는 값의 비트 수를 기준으로 합니다. 실제 실행 중 사용하는 메모리 전체의 크기와는 다를 수 있습니다.

자료형 저장하는 값 크기 변수 선언 예
byte 작은 정수(-128~127) 1바이트(8비트) byte level = 10;
short 정수(-32768~32767) 2바이트(16비트) short count = 1000;
int 정수 4바이트(32비트) int age = 20;
long 큰 정수 8바이트(64비트) long population = 3000000000L;
float 실수 4바이트(32비트) float height = 175.5f;
double 실수 8바이트(64비트) double weight = 65.3;
char 문자 코드 단위 하나 2바이트(16비트) char grade = 'A';
boolean 참/거짓 고정 바이트 크기를 명세에서 정하지 않음 boolean isStudent = true;

💡 참고: char는 UTF-16이라는 문자 표현 방식의 코드 단위 하나를 저장합니다. 'A', '가'는 하나의 char로 표현하지만, 일부 이모지는 두 개의 char가 필요합니다.

3.1 기본 자료형과 참조 자료형 (추가: 2026.10.15)

Java의 자료형은 기본 자료형과 참조 자료형(reference type)으로 나눕니다. 참조 자료형의 변수에는 객체를 가리키는 참조 값을 저장합니다. 여기서 객체는 문자열처럼 프로그램에서 다루는 데이터의 한 단위입니다. 객체의 자세한 내용은 이후에 배웁니다.

int age = 20;
String name = "Kim";
구분 영어 예 변수에 저장하는 것
기본 자료형 primitive type int, double, char, boolean 등 age에는 정수 값 20을 저장합니다.
참조 자료형 reference type String 등 name에는 문자열 객체를 가리키는 참조 값을 저장합니다.

📌 정리: String은 기본 자료형 8개에 포함되지 않습니다. 문자열의 메모리 크기를 고정된 바이트 수로 외우지 않습니다.

⚠️ 주의: char는 작은따옴표(')를 사용하고, String은 큰따옴표(")를 사용합니다.

char grade = 'A';
String name = "Kim";

3.2 float와 double의 차이 (추가: 2026.10.15)

float와 double은 모두 소수점이 있는 실수를 저장합니다. 두 자료형은 사용하는 메모리 크기와 정밀도가 다릅니다. 정밀도(precision)는 숫자를 얼마나 자세하게 표현할 수 있는지를 뜻합니다.

자료형 크기 정밀도(precision)
float 32비트(4바이트) 유효 숫자 약 6~7자리
double 64비트(8바이트) 유효 숫자 약 15~16자리

💡 참고: 유효 숫자는 소수점 아래 자릿수만이 아니라 숫자 전체에서 의미 있는 자릿수를 뜻합니다.

Java에서 175.5처럼 소수점이 있는 숫자는 기본적으로 double입니다. float 변수에 저장하려면 숫자 뒤에 f 또는 F를 붙입니다.

왼쪽의 float는 변수의 자료형을 정하고, 오른쪽의 f는 숫자 리터럴의 자료형을 정합니다. double에서 float로 바꾸면 정밀도가 줄 수 있으므로 Java는 이 변환을 자동으로 하지 않습니다.

float heightFloat = 175.5f;
double heightDouble = 175.5;

System.out.printf("float: %.1f%n", heightFloat);
System.out.printf("double: %.1f%n", heightDouble);

위 코드를 main() 안에서 실행하면 다음과 같이 출력됩니다.

float: 175.5
double: 175.5

float와 double 모두 printf()에서 %f로 출력합니다. 이 교안의 실수 계산 예제에서는 더 높은 정밀도의 double을 기본으로 사용합니다.

3.3 자료형, 변수, 값의 차이 (추가: 2026.10.15)

자료형(type)은 저장할 수 있는 값의 종류와 표현 범위를 정합니다. 변수(variable)는 값을 저장하고 이름으로 사용할 수 있는 공간입니다. 값(value)은 변수에 저장하거나 계산으로 얻는 실제 데이터입니다.

double weight = 65.3;
코드 구분 의미
double 자료형 실수와 특수한 실수 값을 표현하는 자료형입니다.
weight 변수 이름 저장한 값을 이 이름으로 사용합니다.
65.3 값의 직접 표기 코드에 직접 적은 값이므로 리터럴이라고 합니다.

변수에 저장된 값이 달라져도 변수의 자료형은 바뀌지 않습니다.

double weight = 65.3;
weight = 66.0;

weight의 값은 65.3에서 66.0으로 바뀌지만, 자료형은 계속 double입니다. 값은 계산으로도 얻을 수 있습니다. 리터럴은 그중 코드에 값을 직접 적는 표기입니다.

3.4 리터럴이란? (추가: 2026.10.15)

리터럴(literal)은 코드에 직접 적은 값입니다. 변수 이름과 리터럴을 구분해 봅니다.

int age = 20;
코드 의미
int 변수의 자료형
age 값을 저장하는 변수의 이름
20 코드에 직접 적은 정수 리터럴

리터럴에도 자료형이 있습니다. 숫자의 접미사, 따옴표, 키워드에 따라 자료형이 달라집니다.

리터럴 예 종류 Java 자료형
20 정수 리터럴 int
20L 정수 리터럴 long
175.5 실수 리터럴 double
175.5f 실수 리터럴 float
'A' 문자 리터럴 char
"Kim" 문자열 리터럴 String
true, false 논리 리터럴 boolean

💡 참고: 접미사는 숫자 뒤에 붙여 자료형을 지정하는 문자입니다. 뒤의 ‘숫자 뒤에 붙이는 접미사’ 항목에서 살펴봅니다.

int age = 20;
int nextAge = age + 1;

첫 번째 줄의 20과 두 번째 줄의 1은 리터럴입니다. age는 변수이고, age + 1 전체는 값을 계산하는 식입니다. age에 저장된 값이 20이면 nextAge에는 계산 결과인 21이 저장됩니다.

📌 정리: 코드에 값을 직접 적으면 리터럴이고, 저장된 값을 이름으로 사용하면 변수입니다.

3.5 프로그램을 구성하는 기본 단위 (추가: 2026.10.15)

리터럴, 식, 문, 블록은 프로그램을 구성하는 기본 단위입니다. 다음 코드를 main() 안에서 살펴봅니다.

{
    int age = 20;
    int nextAge;
    nextAge = age + 1;
    System.out.println(nextAge);
}

실행 결과:

21
구성 단위 영어 예 역할
리터럴 literal 20, 1 코드에 직접 적은 값
식 expression age + 1 값을 계산하거나 만들어 냅니다.
문 statement nextAge = age + 1; 값을 저장하는 등의 동작을 수행합니다.
블록 block { ... } 여러 문이나 변수 선언 등을 묶습니다.

age + 1은 21을 계산하는 식(expression)입니다. nextAge = age + 1;은 계산한 값을 변수에 저장하는 대입문(statement)입니다. 바깥의 중괄호 { }는 이 코드들을 하나의 블록(block)으로 묶습니다.

💡 참고: 1 같은 리터럴과 age 같은 변수 이름도 식으로 사용할 수 있습니다. 식 안에 다른 식이 들어가고, 문 안에 식이 들어갈 수 있습니다.

⚠️ 주의: 모든 식에 세미콜론(;)을 붙인다고 문이 되는 것은 아닙니다. Java에서 age + 1;만 적으면 컴파일 오류입니다. 대입이나 메서드 호출처럼 문으로 사용할 수 있는 식이 따로 있습니다.

💡 참고: 단순한 대입문이나 메서드 호출문은 세미콜론으로 끝납니다. 블록은 중괄호로 묶으므로 모든 문이 세미콜론으로 끝나는 것은 아닙니다.

3.6 다음 내용으로 넘어가기 전: 식과 문 구분하기 (추가: 2026.10.15)

문(statement)은 프로그램이 수행할 동작을 나타내는 코드입니다. 대입문은 문의 한 종류이며, =이 없어도 문이 될 수 있습니다.

문의 종류 예 수행하는 동작
대입문 age = 20; 변수에 값을 저장합니다.
메서드 호출문 System.out.println(age); 출력 메서드를 실행합니다.
증가문 age++; 변수의 값을 1 증가시킵니다.
조건문 if (age >= 20) { ... } 조건이 참일 때 실행합니다.
반복문 while (age < 20) { ... } 조건이 참인 동안 반복합니다.
반환문 return; 현재 메서드의 실행을 끝냅니다.

💡 참고: ++는 값을 1 증가시키는 연산자입니다. if, while, return의 자세한 사용법은 이후에 배웁니다. 여기서는 문에 여러 종류가 있다는 점을 확인합니다. 표의 ...은 생략 표시이므로 그대로 실행하는 코드는 아닙니다.

대입도 식으로 사용할 수 있습니다.

코드 구분 설명
age + 1 식 더한 값을 계산합니다.
age = 20 대입식 값을 저장하고, 대입한 값 20을 식의 값으로 가집니다.
age = 20; 대입문 대입식 뒤에 세미콜론을 붙여 하나의 동작으로 실행합니다.
System.out.println(age); 메서드 호출문 = 없이도 출력 동작을 실행합니다.

📌 정리: =의 유무로 식과 문을 구분하지 않습니다. 식은 값을 나타내거나 계산하는 데 사용하고, 문은 실행할 동작을 구성합니다. 다만 값을 반환하지 않는 메서드 호출도 식에 포함됩니다.

✅ 확인할 것:

  • 20은 코드에 직접 적은 리터럴이며, 식이기도 합니다.
  • age + 1은 식이지만, age + 1;은 Java에서 올바른 문이 아닙니다.
  • age = 20;과 System.out.println(age);은 모두 문입니다.
  • 여러 문과 변수 선언을 중괄호로 묶으면 블록이 됩니다.

3.7 숫자 뒤에 붙이는 접미사 (추가: 2026.10.15)

175.5f에서 f처럼 숫자 뒤에 붙여 자료형을 지정하는 문자를 접미사라고 합니다. 접미사는 변수의 자료형이 아니라 숫자 리터럴의 자료형을 지정합니다.

접미사 리터럴의 자료형 예 사용 기준
f 또는 F float 175.5f float 실수 리터럴에는 붙입니다.
d 또는 D double 65.3d 실수 리터럴은 기본적으로 double이므로 생략할 수 있습니다.
l 또는 L long 3000000000L long 정수 리터럴에 붙입니다. 숫자 1과 구분하기 쉬운 대문자 L을 사용합니다.

long은 int보다 큰 정수를 저장할 수 있는 64비트(8바이트) 정수 자료형입니다. int의 최댓값은 2147483647이므로, 아래의 3000000000에는 L을 붙여야 합니다.

float height = 175.5f;
double weight = 65.3;       // 65.3d로 적어도 같습니다.
long population = 3000000000L;

⚠️ 주의: float height = 175.5;는 컴파일 오류입니다. 175.5가 double이기 때문입니다. float height = 175.5f;처럼 작성합니다.

💡 참고: 175.5f의 f는 숫자의 자료형을 지정하고, printf()의 %f는 실수를 출력하는 형식을 지정합니다.

3.8 리터럴의 자료형과 크기 (추가: 2026.10.15)

접미사 없는 정수 리터럴은 기본적으로 int(4바이트)입니다. 접미사 없는 실수 리터럴은 기본적으로 double(8바이트)입니다. 아래 크기도 소스 파일의 글자 수가 아니라, 리터럴 자료형이 표현하는 값의 크기를 뜻합니다.

리터럴 예 자료형 값의 크기 구분 방법
20 int 4바이트 접미사 없는 정수
20L long 8바이트 L 또는 l
175.5f float 4바이트 f 또는 F
175.5, 175.5d double 8바이트 실수에서 접미사 생략 또는 d, D
'A', '가' char 2바이트 작은따옴표
true, false boolean 고정 바이트 크기를 명세에서 정하지 않음 참/거짓 키워드
"Kim" String 고정 크기 아님 큰따옴표

byte와 short 전용 리터럴 접미사는 없습니다. 아래의 10과 1000은 모두 int 리터럴이지만, 변수의 범위에 들어가는 정수 상수이므로 그대로 저장할 수 있습니다.

byte level = 10;        // 변수는 1바이트, 리터럴 10은 int형
short count = 1000;     // 변수는 2바이트, 리터럴 1000은 int형
long total = 20;        // int 리터럴 20이 long으로 자동 변환됩니다.
long big = 3000000000L; // 큰 정수 리터럴 자체를 long형으로 지정합니다.

⚠️ 주의: long big = 3000000000;은 컴파일 오류입니다. 왼쪽 변수가 long이어도 접미사 없는 정수 리터럴이 자동으로 long이 되지는 않습니다.

📌 정리: 변수의 자료형과 리터럴의 자료형은 따로 확인합니다. 정수는 기본 int, 실수는 기본 double이며, L과 f로 리터럴의 자료형을 지정할 수 있습니다.

💡 참고: 자료형과 리터럴 규칙은 Java 언어 명세의 자료형과 리터럴을 기준으로 합니다.

4. printf()와 자료형

printf()에서는 출력할 값의 자료형에 맞는 자리표시자를 사용합니다.

자리표시자 의미 예
%d 정수 출력 System.out.printf("%d%n", age);
%f 실수 출력 System.out.printf("%f%n", height);
%.1f 소수점 첫째 자리까지 실수 출력 System.out.printf("%.1f%n", height);
%c 문자 하나 출력 System.out.printf("%c%n", grade);
%b 참/거짓 출력 System.out.printf("%b%n", isStudent);
%s 문자열 출력 System.out.printf("%s%n", name);
%n 줄바꿈 System.out.printf("Hello%n");

5. 자동 형 변환 (수정: 2026.10.15)

형 변환(type conversion)은 값의 자료형이 다른 자료형으로 바뀌는 것입니다. 변환을 직접 표시하는지에 따라 다음과 같이 구분합니다.

구분 영어 뜻 예
자동 형 변환 implicit conversion implicit은 ‘암시적’이라는 뜻입니다. 변환할 자료형을 직접 표시하지 않아도 Java가 변환합니다. double x = 20;
명시적 형 변환(강제 형 변환) explicit conversion / type casting explicit은 ‘명시적’이라는 뜻입니다. 프로그래머가 변환할 자료형을 직접 표시합니다. int x = (int) 3.14;

Java에서 (int)처럼 괄호 안에 자료형을 적어 변환하는 것을 캐스팅(casting)이라고 합니다. 이 교안에서는 자동 형 변환을 implicit conversion, 캐스팅을 사용하는 강제 형 변환을 explicit conversion이라고 부릅니다.

작은 범위의 값을 더 큰 범위의 자료형에 넣을 때는 Java가 자동으로 바꾸어 주는 경우가 있습니다.

public class AutoCasting {
    public static void main(String[] args) {
        int score = 90;
        double scoreDouble = score;

        System.out.printf("%.1f%n", scoreDouble);
    }
}

실행 결과:

90.0

int 값 90이 double 변수에 저장되면서 90.0으로 바뀌었습니다.

⚠️ 주의: 자동 형 변환이 항상 모든 숫자를 정확하게 보존하는 것은 아닙니다. 예를 들어 큰 int를 float로 바꾸면 유효 숫자 제한 때문에 정밀도가 줄 수 있습니다.

6. 강제 형 변환 (수정: 2026.10.15)

큰 범위의 값을 작은 범위의 자료형으로 바꿀 때는 직접 자료형을 적어야 합니다. 이때 일부 값이 사라질 수 있습니다.

아래의 (int) average는 변환할 자료형을 직접 적은 명시적 형 변환(explicit conversion)이며, 타입 캐스팅(type casting)의 예입니다.

public class ManualCasting {
    public static void main(String[] args) {
        double average = 89.7;
        int score = (int) average;

        System.out.printf("%d%n", score);
    }
}

실행 결과:

89

double 값 89.7을 int로 바꾸면 소수점 아래가 사라집니다.

⚠️ 주의: 강제 형 변환은 값이 달라질 수 있으므로 필요한 경우에만 사용합니다.

7. 오버플로우와 언더플로우 (추가: 2026.10.15)

자료형마다 표현할 수 있는 값의 범위가 있습니다. 계산 결과가 그 범위를 벗어나면 예상과 다른 값이 나올 수 있습니다.

7.1 정수의 범위 초과

int의 범위는 -2147483648부터 2147483647까지입니다. 최댓값보다 큰 결과나 최솟값보다 작은 결과가 나오는 정수 계산을 오버플로우(overflow)라고 합니다. Java의 일반적인 정수 덧셈에서는 예외가 발생하지 않고 값이 반대쪽 범위로 돌아갑니다.

다음 코드를 main() 안에서 실행해 봅니다.

int max = 2147483647;
int min = -2147483648;

System.out.println(max + 1);
System.out.println(min - 1);

실행 결과:

-2147483648
2147483647

💡 참고: 정수의 최솟값 아래로 벗어나는 경우를 언더플로우라고 부르기도 합니다. 이 교안에서는 정수의 양쪽 범위 초과를 오버플로우로 설명하고, 실수의 언더플로우와 구분합니다.

7.2 큰 자료형에 저장하기 전에 계산 범위 확인하기

결과를 long 변수에 저장해도, 오른쪽에서 int끼리 먼저 계산하면 오버플로우가 발생할 수 있습니다.

int max = 2147483647;
long wrong = max + 1;
long correct = (long) max + 1;

System.out.println(wrong);
System.out.println(correct);

실행 결과:

-2147483648
2147483648

(long) max처럼 계산 전에 자료형을 바꾸면 덧셈을 long으로 수행합니다. max + 1L처럼 long 리터럴을 사용해도 됩니다.

⚠️ 주의: 계산이 끝난 뒤 (long) (max + 1)로 바꾸어도 이미 발생한 오버플로우는 복구되지 않습니다.

7.3 실수의 오버플로우와 언더플로우

실수에서는 값의 크기뿐 아니라 정밀도에도 제한이 있습니다.

구분 의미 Java에서 나타날 수 있는 결과
오버플로우(overflow) 계산 결과의 절댓값이 너무 큽니다. 양의 무한대 또는 음의 무한대
언더플로우(underflow) 0이 아닌 계산 결과의 절댓값이 너무 작아 표현에 제한이 생깁니다. 정밀도가 낮아지거나, 더 작아지면 0.0 또는 -0.0 
double large = 1.0e308;
double small = 1.0e-300;

System.out.println(large * 10.0);
System.out.println(small * small);

실행 결과:

Infinity
0.0

💡 참고: 1.0e308은 1.0에 10의 308제곱을 곱한 값입니다. 1.0e-300은 1.0을 10의 300제곱으로 나눈 값입니다. Infinity는 무한대를 나타내는 출력입니다.

7.4 Infinity와 NaN은 자료형이 아닌 값 (추가: 2026.10.15)

float와 double은 일반적인 실수 값 외에 특수한 값도 표현할 수 있습니다. Infinity가 출력되어도 변수의 자료형이 바뀌는 것은 아닙니다.

구분 예 의미
자료형 float, double 표현할 수 있는 값의 종류와 범위를 정합니다.
일반적인 실수 값 65.3, 175.5 유한한 실수 값입니다.
양의 무한대 Infinity 양의 방향으로 무한한 값을 나타냅니다.
음의 무한대 -Infinity 음의 방향으로 무한한 값을 나타냅니다.
숫자가 아닌 결과 NaN Not a Number의 약자입니다. 0.0 / 0.0처럼 숫자로 나타낼 수 없는 결과입니다. 
double large = 1.0e308;
double result = large * 10.0;

System.out.println(result);
System.out.println(0.0 / 0.0);

실행 결과:

Infinity
NaN

result의 자료형은 double이고, 저장된 값은 양의 무한대입니다.

💡 참고: Java 코드에서 양의 무한대를 직접 사용하려면 Double.POSITIVE_INFINITY, 음의 무한대는 Double.NEGATIVE_INFINITY, NaN은 Double.NaN으로 적습니다. 이들은 미리 정의된 상수입니다. Infinity나 NaN만 적으면 숫자 리터럴로 인식하지 않습니다. float에도 Float.POSITIVE_INFINITY, Float.NEGATIVE_INFINITY, Float.NaN이 있습니다.

📌 정리: 정수의 범위 초과와 실수의 언더플로우는 다릅니다. 실수의 언더플로우는 단순히 음수가 되는 것이 아니라, 값이 0에 너무 가까워 표현에 제한이 생기는 현상입니다.

8. null과 결측값 구분하기 (추가: 2026.10.15)

8.1 Java의 null과 빈 문자열

null은 가리키는 객체가 없음을 나타내는 값입니다. String 같은 참조 자료형의 변수에 저장할 수 있습니다. null은 Java의 리터럴이지만, int나 double 같은 기본 자료형의 값은 아닙니다.

코드 의미
String name = "Kim"; "Kim" 문자열 객체를 가리킵니다.
String name = ""; 글자가 없는 빈 문자열 객체를 가리킵니다.
String name = null; 가리키는 객체가 없습니다.

빈 문자열 ""은 길이가 0인 문자열입니다. null과는 다릅니다.

String empty = "";
System.out.println(empty.length());

실행 결과:

0

💡 참고: length()는 문자열의 길이를 구하는 메서드입니다. 정확히는 UTF-16 코드 단위의 개수를 반환합니다.

String name = null;
System.out.println(name.length()); // NullPointerException 발생

name이 가리키는 객체가 없으므로 문자열의 기능을 실행할 수 없습니다. 이때 발생하는 실행 중 오류가 NullPointerException입니다.

⚠️ 주의: int age = null;이나 boolean flag = null;은 컴파일 오류입니다. 기본 자료형에는 null을 저장할 수 없습니다.

8.2 데이터 분석에서 사용하는 NA

데이터 분석에서 결측값(missing value)은 수집되지 않았거나 확인되지 않아 빠진 데이터를 뜻합니다. R에서 사용하는 NA(Not Available)는 결측값을 나타냅니다.

이름 나이
Kim 20
Lee NA

Lee의 나이가 0이라는 뜻이 아닙니다. 나이가 입력되지 않았거나 확인되지 않았다는 뜻입니다. 위 표는 결측값의 개념을 설명하는 예이며, Java 코드가 아닙니다.

표현 사용하는 맥락 의미
0 숫자 데이터 실제 숫자 값 0
"" 문자열 글자가 없는 빈 문자열
null Java의 참조 값 가리키는 객체가 없음
NA R의 결측값 데이터가 빠져 있거나 확인되지 않음
NaN 실수 연산 및 데이터 분석 숫자로 나타낼 수 없는 결과. 분석 도구에서는 결측값 표시에 사용하기도 함

💡 참고: Python 데이터 분석 라이브러리인 pandas에서는 자료형에 따라 None, NaN, pd.NA 등을 결측값 표시에 사용합니다. pd.NA의 pd는 pandas를 불러올 때 흔히 사용하는 이름입니다. 이 표기들이 모든 언어에서 같은 의미로 쓰이는 것은 아닙니다.

Java에는 결측값을 뜻하는 NA라는 기본 키워드가 없습니다. 참조 자료형에서 null을 결측값 표현에 사용할 수 있지만, 데이터가 없는 이유까지 알려 주지는 않습니다. 문자열 "NA" 역시 별도 처리 규칙이 없으면 두 글자로 된 문자열일 뿐입니다.

📌 정리: null, NA, NaN은 모두 같은 값이 아닙니다. 객체가 없는 상태, 빠진 데이터, 숫자로 나타낼 수 없는 결과를 구분합니다. 결측값을 임의로 0으로 바꾸면 평균 같은 계산 결과가 달라질 수 있습니다.

💡 참고: 결측값 표기는 R의 NA 문서와 pandas의 결측값 안내를 참고합니다.

9. 다른 예제 1: 평균 점수 계산

정수끼리 나누면 결과도 정수이며, 소수점 아래는 버립니다. 평균처럼 소수점 결과가 필요하면 double을 사용합니다.

public class AverageScore {
    public static void main(String[] args) {
        int korean = 80;
        int english = 90;
        int math = 85;

        double average = (korean + english + math) / 3.0;

        System.out.printf("average: %.1f%n", average);
    }
}

실행 결과:

average: 85.0

10. 다른 예제 2: 할인 가격 계산

가격은 정수로 저장하고, 할인율은 실수로 저장할 수 있습니다.

public class DiscountPrice {
    public static void main(String[] args) {
        int price = 12000;
        double discountRate = 0.1;
        int discount = (int) (price * discountRate);
        int payment = price - discount;

        System.out.printf("discount: %d%n", discount);
        System.out.printf("payment: %d%n", payment);
    }
}

실행 결과:

discount: 1200
payment: 10800
