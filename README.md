# Teaching Site

이 폴더는 `teaching/materials`와 `teaching/courses`를 바탕으로 만든 정적 사이트 결과물입니다.

공개용 저장소 `vibecoding-lab-site`로 복사한 뒤 GitHub Pages 또는 Vercel로 배포할 수 있습니다.

로컬에서 확인할 때는 프로젝트 루트에서 다음 명령을 실행합니다.

```powershell
python -m http.server 8000 -d teaching/site
```

브라우저에서 다음 주소를 엽니다.

```text
http://localhost:8000/
```

자료실은 다음 주소에서 확인합니다.

```text
http://localhost:8000/materials/
```
